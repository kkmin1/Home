수렴·발산과 비동차 방정식

경제수학 II · 차분방정식 · 1장. 차분방정식의 기초와 해법

해의 발산, 진동, 수렴 조건

\(| \phi | <1\; \rightarrow \; \lim\limits_{t \to \infty } {y_{t}} \,=0\) ; 해는 수렴한다.

\(| \phi | >1\; \rightarrow \; \lim\limits_{t \to \infty } {y_{t}} \,= \infty\) ; 해는 발산한다.

\(\phi =1\; \rightarrow \;y_{t} \,=A\) ; 해는 일정하다.

\(\phi =-1\; \rightarrow \;y_{t} \,=(-1) ^{t} A\) ; 해는 진동한다.

\(\phi >0\; \rightarrow \;y_{t} \,\)는 부호 불변

\(\phi <0\; \rightarrow \;y_{t} \,\)는 부호 변동(+,-,+,_,...)

예) 다음 차분방정식의 해를 구하고 수렴, 발산, 진동을 판정하시오. 단, \(y_{0} \,=\,3\)

(a) \(y_{t} \,=\,2y_{t-1}\)

(b) \(y_{t} \,=\,0.7y_{t-1}\)

(c) \(y_{t} \,=\,-2y_{t-1}\)

(d) \(y_{t} \,=\,-0.7y_{t-1}\)

(e) \(y_{t} \,=\,y_{t-1}\)

(f) \(y_{t} \,=\,-y_{t-1}\)

(풀이)

(a) \(y_{t} \,=\,3(2) ^{t}\) ; \(t\)가 증가함에 따라 \(y_{t}\)는 무한대로 발산한다.

(b) \(y_{t} \,=\,3(0.7) ^{t}\) ; \(t\)가 증가함에 따라 \(y_{t}\)는 0으로 수렴한다.

(c) \(y_{t} \,=\,3(-2) ^{t}\) ; \(t\)가 증가함에 따라 \(y_{t}\)는 +, - 진동하면서 무한대로 발산한다.

(d) \(y_{t} \,=\,3(-0.7) ^{t}\) ; \(t\)가 증가함에 따라 \(y_{t}\)는 +, - 진동하면서 0으로 수렴한다.

(e) \(y_{t} \,=\,3\) ; \(t\)가 증가함에 따라 \(y_{t}\)는 3으로 일정하다.

(f) \(y_{t} \,=\,3(-1) ^{t}\) ; \(t\)가 증가함에 따라 \(y_{t}\)는 +3, -3 으로 진동한다.

(풀이끝)

1차 선형 비동차 차분방정식(linear non-homogeneous difference equation)

a) 비동차 부분이 상수인 경우(non-homogeneous but autonomous)

i) \(\phi \, != 1\) 인 경우

(방법 1)

\(y_{t} \,=\, \alpha + \phi y_{t-1}\)

\(y_{t} \,=\, \alpha + \phi y_{t-1} \,=\, \alpha + \phi ( \alpha + \phi y_{t-2} )= \alpha + \phi \alpha + \phi^{2} y_{t-2}\)

\(y_{t} \,=\, \alpha + \phi \alpha + \phi^{2} y_{t-2} \,=\, \alpha + \phi \alpha + \phi^{2} (\, \alpha + \phi y_{t-3} )\,=\, \alpha + \phi \alpha + \phi^{2} \alpha + \phi^{3} y_{t-3}\)

\(\vdots\)

\(y_{t} \,=\, \phi^{t} y_{0} \,+\, \alpha \sum\limits_{i=0}^{t-1} \phi^{i}\)

\(= \phi^{t} y_{0} \,+\, \alpha \frac{1- \phi^{t}}{1- \phi }\)

\(= \phi^{t} (y_{0} - \frac{\alpha }{1- \phi } )\,+\, \frac{\alpha }{1- \phi }\)

∴ \(y_{t} = \phi^{t} (y_{0} - \frac{\alpha }{1- \phi } )\,+\, \frac{\alpha }{1- \phi }\)

(방법 2)

이는 중첩의 원리를 이용하여 다음과 같이 쉽게 구할 수 있다.

비동차 차분방정식의 경우 일반해는 특수해 + 여함수로 표현 가능하므로[4]

여함수는 동차차분방정식의 해이므로 \(y_{t} \,=\, \phi y_{t-1}\) 의 해는 \(y_{t} =A \phi^{t} \,\)

하나의 특수해는 \(y_{t} \,\)가 상수 일 때 만족해야 하는 것으로 구할 수 있다.

\(y_{t} \,=\,k\) 라 하면

\(k\,=\, \alpha + \phi k\)

i) \(\phi != 1\) 인 경우

\(k\,=\, \frac{\alpha }{1- \phi } \,=\,y_{t}\)

따라서 일반해는

\(y_{t} =A \phi^{t} \,+ \frac{\alpha }{1- \phi }\) ................①

이에 \(t=0\)를 대입하면

\(y_{0} \,=\,A+ \frac{\alpha }{1- \phi }\)

⇒ \(\,A\,=\,y_{0} - \frac{\alpha }{1- \phi }\)

이를 ①에 대입하면

\(y_{t} =(y_{0} \,-\, \frac{\alpha }{1- \phi } ) \phi^{t} \,+ \frac{\alpha }{1- \phi }\)

앞에서 구한 것과 같은 결과이다.

여기서 특수해 \(\, \frac{\alpha }{1- \phi } \,\)는 경제적으로 중요한 의미를 갖고 있다.

\(\, \frac{\alpha }{1- \phi } \,\)는 \(y_{t}\)가 상수로 고정일 때를 가정하고 구한 것이다. 즉 \(y_{t} \,=\,y_{t+1} \,=\,k\)

따라서 \(y_{t}\)는 시간에 따라 변하지 않는다. 이러한 상태를 경제학에서 정상상태(steady state), 또는 균형점(equilibrium point)라고 한다.[5]

ii) \(\phi \,=1\) 인 경우

\(y_{1} \,=\, \alpha +y_{0}\)

\(y_{2} \,=\, \alpha +y_{1} \,=\,2 \alpha \,+\,y_{0}\)

\(y_{3} \,=\, \alpha +y_{2} \,=\,3 \alpha \,+\,y_{0}\)

\(\vdots\)

\(y_{t} \,=\,t \alpha +y_{0} \,\)

∴ \(y_{t} \,=\,t \alpha +y_{0} \,\)

해의 수렴, 발산

\(| \phi |\,<\,1\)인 경우 시간이 지남에 따라 해는 균형점 \(\, \frac{\alpha }{1- \phi }\)로 수렴한다. 초기상태가 어디에서 시작하든 이 균형점으로 점차 수렴한다. 따라서 이런 균형점을 전체적 점진적 안정상태(globally asymptotically stable steady state)라 한다.[6]

\(| \phi |\,>\,1\)인 경우 시간이 지남에 따라 해는 양 또는 음의 무한대로 발산한다.

초기값이 \(\,y_{0} \,=\, \frac{\alpha }{1- \phi }\)인 경우 \(\phi\)에 관계없이 해는 \(\, \frac{\alpha }{1- \phi }\)이고 시간에 따라 변하지 않는다. 따라서 이 균형점을 안정상태(stable steady state or stable equilibrium point)라 한다.

여함수의 형태에 따라 해의 경로가 달라진다.

i) \(\phi \,>\,1,\;y_{0} \,>\, \frac{\alpha }{1- \phi }\) ⇒ Increasing, monotonic, unbounded

ii) \(\phi \,>\,1,\;y_{0} \,<\, \frac{\alpha }{1- \phi }\) ⇒ Decreasing, monotonic, unbounded

iii) \(0< \phi \,<\,1,\;y_{0} \,<\, \frac{\alpha }{1- \phi } \,=\,y*\) ⇒ Increasing, monotonic, bounded, convergent

iv) \(0< \phi \,<\,1,\;y_{0} \,>\, \frac{\alpha }{1- \phi } \,=\,y*\) ⇒ Decreasing, monotonic, bounded, convergent

v) \(-1< \phi \,<\,0\;\)⇒ bounded, oscillatory, convergent

vi) \(\phi \,<\,-1\;\)⇒ unbounded, oscillatory, divergent

vii) \(\phi \,=\,1\,,\, \alpha \,=\,0\,\) ⇒ constant

viii) \(\phi \,=\,1\,,\, \alpha \,>\,0\,\) ⇒ constant increasing

xi) \(\phi \,=\,1\,,\, \alpha \,<\,0\,\) ⇒ constant decreasing

x) \(\phi \,=\,-1\;\)⇒ finite, bounded oscillatory

예) 다음 차분방정식의 해를 구하라.

(a) \(y_{t} \,=\,2y_{t-1} \,-3\,\), \(y_{0} \,=\,4\)

(b) \(y_{t} \,=\,y_{t-1} \,+\,10\,\), \(y_{0} \,=\,5\)

(풀이)

(a) \(\phi \,=\,2 != 1\) 이므로 첫 번째 공식을 대입한다.

\(y_{t} = \phi^{t} (y_{0} - \frac{\alpha }{1- \phi } )\,+\, \frac{\alpha }{1- \phi }\)

⇒ \(y_{t} =2^{t} (4\,-\, \frac{-3}{1-2} )\,+\, \frac{-3}{1-2}\)

\(=\,2^{t} \,+3\)

중첩의 원리를 적용하면 더 쉽게 풀 수 있다.

특수해는 추측에 의해 \(y_{t} \,=\,k\) 라 하면[7]

\(k\,=\,2k\,-\,3\) ⇒ \(k\,=\,3\)

∴ \(y_{p} \,=\,3\)

동차해는 \(y_{t} \,=\,2y_{t-1} \,\)를 풀면

\(y_{c} \,=\,A2^{t}\)

따라서 일반해는

\(y_{t} \,=\,y_{p} \,+\,y_{c} \,=\,A2^{t} \,+\,3\)

초기조건을 대입하면

\(y_{0} \,=\,A\,+\,3\,=\,4\) ⇒ \(A\,=\,1\)

∴ \(y_{t} \,=\,2^{t} \,+\,3\)

\(y_{t}\)는 3에서 양의 무한대로 발산한다.

(b) \(\phi \,=\,1\) 이 아니므로 두 번째 공식을 대입한다.

\(y_{t} \,=\,t \alpha +y_{0} \,\)

⇒ \(y_{t} \,=\,10t+5\,\)

중첩의 원리를 적용하면 더 쉽게 풀 수 있다.

특수해는 다음과 같이 구한다.

\(y_{t} \,=\,k\) 라 하면 차분방정식을 만족하지 못하므로 \(y_{t} \,=\,kt\) 라 하면

\(kt\,=\,k(t-1)\,+\,10\) ⇒ \(k\,=\,10\)

∴ \(y_{p} \,=\,10t\)

동차해는 \(y_{t} \,=\,y_{t-1} \,\)를 풀면

\(y_{c} \,=\,A\)

따라서 일반해는

\(y_{t} \,=\,y_{p} \,+\,y_{c} \,=\,A\,+\,10t\)

\(y_{0} \,=\,A\,=\,5\)

∴ \(y_{t} \,=\,10t\,+\,5\)

(풀이끝)

b) 비동차 부분이 t의 함수인 경우(non-autonomous difference equation)

\(y_{t} \,=\, \alpha + \beta t+ \phi y_{t-1}\)

(방법 1)

\(y_{t} \,=\, \alpha + \beta t+ \phi ( \alpha + \beta (t-1)+ \phi y_{t-2} )\,=\, \alpha + \beta t\,+ \phi ( \alpha + \beta (t-1))+ \phi^{2} y_{t-2} \,\)

\(y_{t} \,=\, \alpha + \beta t\,+ \phi ( \alpha + \beta (t-1))+ \phi^{2} ( \alpha + \beta (t-2)\,+ \phi y_{t-3} )\,=\, \alpha + \beta t\,+ \phi ( \alpha + \beta (t-1))+ \phi^{2} ( \alpha + \beta (t-2)\,+ \phi y_{t-3} )\,\)

\(\,=\, \alpha + \beta t\,+ \phi \alpha + \phi \beta (t-1))+ \phi^{2} \alpha + \phi^{2} \beta (t-2)\,+ \phi^{3} y_{t-3} \,\)

\(\vdots\)

\(y_{t} \,= \phi^{t} y_{0} + \alpha \sum\limits_{i=0}^{t-1} \phi^{i} + \beta \sum\limits_{i=0}^{t-1} \phi^{i} (t-i)\)

i) \(\phi \, != \,1\) 인 경우

\(\sum\limits_{i=0}^{t-1} \phi^{i} (t-i)\,=\,t \sum\limits_{i=0}^{t-1} \phi^{i} \,- \sum\limits_{i=0}^{t-1} i \phi^{i}\)

여기서 우변의 두 번째 항은

\(\sum\limits_{i=0}^{t-1} i \phi^{i} \,= \phi \,+\,2 \phi^{2} +3 \phi^{3} +...+(t-1) \phi^{t-1}\)

\(S\,= \phi \,+\,2 \phi^{2} +3 \phi^{3} +...+(t-1) \phi^{t-1}\) .......... ① 라 하면

\(\phi S\,= \phi^{2} \,+\,2 \phi^{3} +3 \phi^{4} +...+(t-1) \phi^{t}\) ...........②

①에서 ②를 빼면

\((1- \phi )S\,= \phi \,+\, \phi^{2} + \phi^{3} +...+ \phi^{t-1} \,-\,(t-1) \phi^{t}\)

\(= \frac{\phi (1- \phi^{t-1} )}{1- \phi } -(t-1) \phi^{t}\)

∴ \(S\,= \frac{\phi (1- \phi^{t-1} )}{(1- \phi ) ^{2}} - \frac{(t-1) \phi^{t}}{1- \phi }\)

\(\sum\limits_{i=0}^{t-1} \phi^{i} (t-i)\,=\,t \frac{1- \phi^{t}}{1- \phi } \,-\)\(\frac{\phi (1- \phi^{t-1} )}{(1- \phi ) ^{2}} + \frac{(t-1) \phi^{t}}{1- \phi }\)

\(= \frac{t-t \phi^{t}}{1- \phi } - \frac{\phi - \phi^{t}}{(1- \phi ) ^{2}} + \frac{t \phi^{t} - \phi^{t}}{1- \phi }\)

\(= \frac{t- \phi^{t}}{1- \phi } - \frac{\phi - \phi^{t}}{(1- \phi ) ^{2}}\)

\(= \frac{t}{1- \phi } - \frac{\phi^{t} (1- \phi )}{(1- \phi ) ^{2}} - \frac{\phi - \phi^{t}}{(1- \phi ) ^{2}}\)

\(= \frac{t}{1- \phi } + \frac{\phi^{t+1} \,-\, \phi }{(1- \phi ) ^{2}}\)

따라서 차분방정식의 해는

\(y_{t} \,= \phi^{t} y_{0} + \alpha \sum\limits_{i=0}^{t-1} \phi^{i} + \beta \sum\limits_{i=0}^{t-1} \phi^{i} (t-i)\)

\(= \phi^{t} y_{0} + \alpha \frac{1- \phi^{t}}{1- \phi } + \beta\)\(( \frac{t}{1- \phi } + \frac{\phi^{t+1} \,- \phi }{(1- \phi ) ^{2}} )\)

\(=(y_{0} - \frac{\alpha }{1- \phi } + \frac{\beta \phi }{(1- \phi ) ^{2}} ) \phi^{t} \,+ \frac{\alpha }{1- \phi } - \frac{\beta \phi }{(1- \phi ) ^{2}} + \frac{\beta }{1- \phi } t\)

∴ \(y_{t} =(y_{0} - \frac{\alpha }{1- \phi } + \frac{\beta \phi }{(1- \phi ) ^{2}} ) \phi^{t} \,+ \frac{\alpha }{1- \phi } - \frac{\beta \phi }{(1- \phi ) ^{2}} + \frac{\beta }{1- \phi } t\)

ii) \(\phi \,=\,1\) 인 경우

\(y_{t} \,= \phi^{t} y_{0} + \alpha \sum\limits_{i=0}^{t-1} \phi^{i} + \beta \sum\limits_{i=0}^{t-1} \phi^{i} (t-i)\)

\(\,=y_{0} + \alpha \sum\limits_{i=0}^{t-1} 1+ \beta \sum\limits_{i=0}^{t-1} (t-i)\)

\(\,=y_{0} + \alpha t+ \beta (t^{2} - \frac{t(t-1)}{2} )\), (∵ \(\sum\limits_{i=1}^{t-1} i\,=\, \sum\limits_{j=1}^{t} (j-1\,)\,=\, \frac{t(t+1)}{2} \,-\,t\,=\, \frac{t(t-1)}{2}\))

\(\,=y_{0} + \alpha t+ \beta ( \frac{t^{2} \,+\,t}{2} )\)

\(\,=y_{0} + \frac{\beta }{2} t^{2} \,+\, \left( \alpha + \frac{\beta }{2} \right) t\)

(방법 2)

중첩의 원리를 이용해 해를 도출할 수 있다.

i) \(\phi \, != \,1\) 인 경우

여함수는 동차차분방정식의 해이므로 \(y_{t} \,=\, \phi y_{t-1}\) 의 해는 \(y_{t} =A \phi^{t} \,\)

특수해를 \(pt+q\) 라 하고 이를 식에 대입하면[8]

\(pt+q\,=\, \alpha + \beta t\,+ \phi [p(t-1)+q]\)

⇒ \(pt+q\,=\, \alpha + \beta t\,+ \phi pt- \phi p+ \phi q\)

⇒ \((p- \beta - \phi p)t\,+\,q- \alpha + \phi p- \phi q\,=\,0\)

모든 \(t\)에 관계없이 항상 성립하려면

\(p- \beta - \phi p\,=\,0\) ⇒ \(p\,=\, \frac{\beta }{1- \phi }\)

\(\,q- \alpha + \phi p- \phi q\,=\,0\) ⇒ \(q\,=\, \frac{\alpha - \phi p}{1- \phi } \,=\, \frac{\alpha }{1- \phi } \,-\, \frac{\beta \phi }{(1- \phi ) ^{2}}\)

따라서 특수해는

\(y_{p} = \frac{\alpha }{1- \phi } - \frac{\beta \phi }{(1- \phi ) ^{2}} + \frac{\beta }{1- \phi } t\)

따라서 일반해는

\(y_{t} =A \phi^{t} \,+ \frac{\alpha }{1- \phi } - \frac{\beta \phi }{(1- \phi ) ^{2}} + \frac{\beta }{1- \phi } t\)

위 식에 초기값 \(y_{0}\)를 대입하면

\(y_{0} =A\,+ \frac{\alpha }{1- \phi } - \frac{\beta \phi }{(1- \phi ) ^{2}}\)

∴ \(A\,=\,y_{0} \,-\, \frac{\alpha }{1- \phi } + \frac{\beta \phi }{(1- \phi ) ^{2}}\)

따라서 일반해는

\(y_{t} =(y_{0} - \frac{\alpha }{1- \phi } + \frac{\beta \phi }{(1- \phi ) ^{2}} ) \phi^{t} \,+ \frac{\alpha }{1- \phi } - \frac{\beta \phi }{(1- \phi ) ^{2}} + \frac{\beta }{1- \phi } t\)

(방법 1)과 같은 결과이다.

ii) \(\phi \,=\,1\) 인 경우

여함수는 동차차분방정식의 해이므로 \(y_{t} \,=\,y_{t-1}\) 의 해는 \(y_{t} =A\,\)

특수해를 \(pt+q\) 라 하면 동차방정식을 만족하지 못하므로 특수해를 \(pt^{2} +qt+r\) 라 하고 이를 식에 대입하면

\(pt^{2} +qt\,+\,r\,=\, \alpha + \beta t\,+[p(t-1) ^{2} +q(t-1)\,+\,r]\), (∵ \(\phi \,=\,1\))

⇒ \(pt^{2} +qt\,+\,r\,=\, \alpha + \beta t\,+pt^{2} -2pt\,+p+qt-q\,+\,r\)

⇒ \(pt^{2} +qt\,+\,r\,=\,pt^{2} +\,( \beta -2p\,+\,q)t\,+ \alpha \,+\,p-q\,+\,r\)

이 식이 항상 성립하기 위해서는

\(q\,=\, \beta \,-\,2p\,+q\) ⇒ \(p\,=\, \frac{\beta }{2}\)

\(r\,=\, \alpha \,+\,p\,-q\,+\,r\) ⇒ \(\,q\,=\, \alpha \,+\,p\,=\, \alpha \,+\, \frac{\beta }{2}\)

r은 임의의 수가 가능하므로 0이라 하면

∴ \(y_{p} \,=\, \frac{\beta }{2} t^{2} \,+\, \left( \alpha + \frac{\beta }{2} \right) t\)

따라서 일반해는

∴ \(y_{t} \,=\,A\,+\, \frac{\beta }{2} t^{2} \,+\, \left( \alpha + \frac{\beta }{2} \right) t\)

초기조건을 대입하면

\(y_{0} \,=\,A\,\)

∴ \(y_{t} \,=\,y_{0} \,+\, \frac{\beta }{2} t^{2} \,+\, \left( \alpha + \frac{\beta }{2} \right) t\)

(방법 1)과 같은 결과이다.

해의 수렴, 발산

if \(0<\phi <1\) 이면, 해는 다음 값으로 수렴한다.

\(\lim\limits_{t \to \infty } y_{t} = \frac{\alpha }{1- \phi } - \frac{\beta \phi }{(1- \phi ) ^{2}} + \frac{\beta }{1- \phi } t\)

if \(\phi \,=\,1\) 이면, 해는 항상 양 혹은 음의 무한대로 발산한다.

예) 다음 차분방정식의 해를 구하여라.

(a) \(y_{t+1} \,+\,y_{t} =\,2t+1\), \(y_{0} \,=\,0\)

(b) \(y_{t+1} \,=\,3y_{t} \,+\,2t-1\), \(y_{0} \,=\,1\)

(c) \(y_{t+1} \,=\,y_{t} \,+\,2t\,+1\), \(y_{0} \,=\,1\)

(풀이)

(a)

(방법1)

공식을 적용하려면 공식에 맞게 \(t\)의 기간을 맞춰 주어야 한다.

\(y_{t+1} \,+\,y_{t} =\,2t+1\) ⇒ \(y_{t} \,=\,-y_{t-1} +\,2t\,-1\)

따라서 \(\phi \,=\,-1,\, \alpha \,=\,-1,\, \beta \,=\,2\)

위 공식에 대입하면

\(y_{t} =(y_{0} - \frac{\alpha }{1- \phi } + \frac{\beta \phi }{(1- \phi ) ^{2}} ) \phi^{t} \,+ \frac{\alpha }{1- \phi } - \frac{\beta \phi }{(1- \phi ) ^{2}} + \frac{\beta }{1- \phi } t\)

⇒ \(y_{t} =(0+ \frac{1}{2} - \frac{2}{4} )(-1) ^{t} \,- \frac{1}{2} + \frac{2}{4} + \frac{2}{2} t\,=\,t\)

∴ \(y_{t} \,=\,t\)

(방법2)

중첩의 원리를 적용하면

여함수는 동차차분방정식의 해이므로 \(y_{t+1} \,=\,-y_{t}\) 의 해는 \(y_{c} =A(-1) ^{t} \,\)

특수해를 \(pt+q\) 라 하고 이를 식에 대입하면

\(p(t+1)+q\,=\,2t\,+\,1\,-(pt+q)\)

⇒ \(pt+p\,+\,q\,=\,1+2t\,-pt-q\)

⇒ \(pt+p\,+\,q\,=\,(2\,-p)t\,+\,1-q\)

모든 \(t\)에 관계없이 항상 성립하려면

\(p\,=\,2-p\,\) ⇒ \(p\,=\,1\)

\(\,p\,+\,q\,=\,1\,-q\,\) ⇒ \(q\,=\,0\)

따라서 특수해는

\(y_{p} =t\)

따라서 일반해는

\(y_{t} =A(-1) ^{t} \,+\,t\)

\(y_{0} =A\,=\,0\)

∴ \(y_{t} =\,t\)

(b)

(방법1)

공식을 적용하려면 공식에 맞게 \(t\)의 기간을 맞춰 주어야 한다.

\(y_{t+1} \,=\,3y_{t} \,+\,2t-1\) ⇒ \(y_{t} \,=\,3y_{t-1} \,+\,2t-3\)

\(\phi \,=\,3,\, \alpha \,=\,-3,\, \beta \,=\,2\)

위 공식에 대입하면

\(y_{t} =(y_{0} - \frac{\alpha }{1- \phi } + \frac{\beta \phi }{(1- \phi ) ^{2}} ) \phi^{t} \,+ \frac{\alpha }{1- \phi } - \frac{\beta \phi }{(1- \phi ) ^{2}} + \frac{\beta }{1- \phi } t\)

\(=(1- \frac{-3}{1-3} + \frac{2(3)}{(1-3) ^{2}} )3^{t} \,+ \frac{-3}{1-3} - \frac{2(3)}{(1-3) ^{2}} + \frac{2}{1-3} t\)

\(=(1- \frac{3}{2} + \frac{3}{2} )3^{t} \,+ \frac{3}{2} - \frac{3}{2} -t\)

\(=3^{t} \,-t\)

(방법2)

방정식의 동차부분은 \(y_{t+1} \,=\,3y_{t} \,\)

따라서 여함수는 \(A3^{t}\)

비동차 부분의 특수해를 \(pt\,+\,q\) 라 하면

\(p(t+1)+q\,=3(pt+q)+2t-1\,\)

⇒ \(pt+p+q\,=3pt+3q+2t-1\,\)

⇒ \(2pt+2t+2q-p-1\,=\,0\)

⇒ \(t(2p+2)+2q-p-1\,=\,0\)

이것이 항상 성립하기 위해서는

\(2p+2\,=\,0\), \(2q-p-1\,=\,0\)

∴ \(p\,=\,-1,\,q\,=\,0\)

따라서 특수해는 \(-t\)

따라서 일반해는 \(y_{t} \,=\,A3^{t} \,-t\)

\(y_{0} \,=\,1\) 이므로 이를 대입하면 \(A\,=\,1\)

따라서 일반해는 \(y_{t} \,=\,3^{t} \,-t\)

이상에서 알 수 있듯이 복잡한 공식을 외우는 것보다 직접 푸는 것이 더 효과적일 수 있다.

(c)

(방법 1)

\(y_{t+1} \,=\,y_{t} \,+\,2t\,+1\) ⇒ \(y_{t} \,=\,y_{t-1} \,+\,2t\,-1\)

따라서 \(\phi \,=\,1,\, \alpha \,=\,-1,\, \beta \,=\,2\)

\(\phi \,=\,1\)인 경우의 공식에 대입하면

\(y_{t} \,=\,1\,+\, \frac{2}{2} t^{2} \,+\, \left( -1+ \frac{2}{2} \right) t\)

\(y_{t} \,=\,1\,+\,t^{2} \,\)

(방법 2)

방정식의 동차부분은 \(y_{t+1} \,=\,y_{t} \,\)

따라서 여함수는 \(y_{c} \,=\,A\)

특수해를 \(pt+q\) 라 하면 동차방정식을 만족하지 못하므로 특수해를 \(pt^{2} +qt+r\) 라 하고 이를 식에 대입하면

\(p(t+1) ^{2} +q(t+1)\,+\,r\,=\,1+2t\,+pt^{2} +qt\,+\,r\)

⇒ \(pt^{2} +\,2pt\,+\,p\,+qt+q\,+\,r\,=\,1+2t\,+pt^{2} +qt\,+\,r\)

⇒ \(pt^{2} +\,(2p+q)t\,+\,p\,+q\,+\,r\,=\,pt^{2} +(q+2)t\,+\,r\,+\,1\)

이것이 항상 성립하기 위해서는

\(2p\,+\,q\,=\,q\,+\,2\) ⇒ \(p\,=\,1\)

\(p\,+\,q\,+\,r\,=\,r\,+\,1\) ⇒ \(q\,=\,0\)

r은 임의의 수이므로 0으로 놓는다.

\(y_{p} \,=\,t^{2}\)

일반해는

\(y_{t} \,=\,A\,+\,t^{2}\)

\(y_{0} \,=\,A\,=\,1\)

∴ \(y_{t} \,=\,1\,+\,t^{2}\)

(풀이끝)

비동차항이 상수가 아니라 t의 함수라면 경험에 의해 다음이 알려져 있다.

비동차항의 형태

특수해의 형태

상수

\(y_{p} \,=\,a\), a는 상수

t의 1차식

\(y_{p} \,=\,a+bt\)

t의 2차식

\(y_{p} \,=\,a+bt+ct^{2}\)

\(\alpha^{t}\)

\(y_{p} \,=\,a \alpha^{t}\)

\(u\,\sin \theta t\,+\,v\,\cos \theta t\)

\(y_{p} \,=\,a\,\sin \theta t\,+\,b\,\cos \theta t\)

예) 다음 차분방정식을 풀어라

\(y_{t+1} \,=\,(1- \lambda )y_{t} \,+\, \lambda t^{2}\), \(\lambda\)는 상수, \(0\,<\, \lambda \,<\,1\)

(풀이)

방정식의 동차부분은 \(y_{t+1} \,=\,(1- \lambda )y_{t} \,\)

따라서 여함수는 \(y_{c} \,=\,A(1- \lambda ) ^{t}\)

비동차 부분의 특수해를 \(y_{p} \,=\,at^{2} \,+\,bt\,+\,c\) 라 하면[9]

\(\,a(t+1) ^{2} \,+\,b(t\,+1\,)\,+\,c\,=\,(1- \lambda )(at^{2} \,+\,bt\,+\,c)\,+\, \lambda t^{2}\)

⇒ \(\,at^{2} \,+2at\,+\,a+\,bt\,+b\,+\,c\,=\,[a(1- \lambda )+ \lambda ]t^{2} \,+\,(1- \lambda )bt\,+\,(1- \lambda )c\)

이 식이 항상 성립하기 위해서는

\(a\,=\,a(1- \lambda )+ \lambda\) ⇒ \(a\,=\,1\)

\(2a+b\,=\,(1- \lambda )b\) ⇒ \(2+b\,=\,(1- \lambda )b\) ⇒ \(b\,=\,- \frac{2}{\lambda }\)

\(a+b+c\,=\,(1- \lambda )c\) ⇒ \(1\,-\, \frac{2}{\lambda } \,+\,c\,=\,(1- \lambda )c\) ⇒ \(c\,=\, \frac{2- \lambda }{\lambda^{2}}\)

따라서 특수해는

\(y_{p} \,=\,at^{2} \,+\,bt\,+\,c\)

\(=\,t^{2} \,- \frac{2}{\lambda } t\,- \frac{2- \lambda }{\lambda^{2}} \,\)

따라서 일반해는

\(y_{t} \,=\,A(1- \lambda ) ^{t} \,+\,t^{2} \,- \frac{2}{\lambda } t\,- \frac{2- \lambda }{\lambda^{2}} \,\)

\(y_{0} \,=\,A\,- \frac{2- \lambda }{\lambda^{2}} \,\)

⇒ \(\,A\,=\,y_{0} \,+\, \frac{2- \lambda }{\lambda^{2}} \,\)

∴ \(y_{t} \,=\,(y_{0} \,+\, \frac{2- \lambda }{\lambda^{2}} )\,(1- \lambda ) ^{t} \,+\,t^{2} \,- \frac{2}{\lambda } t\,- \frac{2- \lambda }{\lambda^{2}} \,\)

\(0\,<\, \lambda \,<\,1\) 이므로 t가 무한대로 갈수록 \(y_{t} \,\)는 \(\,t^{2} \,- \frac{2}{\lambda } t\,- \frac{2- \lambda }{\lambda^{2}} \,\)로 수렴한다.

(풀이끝)

c) 비동차 부분이 외생변수이거나 확률변수인 경우

\(y_{t} \,=\, \phi y_{t-1} + \gamma x_{t}\)

이 식의 해는

\(y_{t} \,=\, \phi y_{t-1} + \gamma x_{t}\)

\(y_{t} \,=\, \phi ( \phi y_{t-2} + \gamma x_{t-1} )+ \gamma x_{t} \,=\, \phi^{2} y_{t-2} \,+ \phi \gamma x_{t-1} + \gamma x_{t}\)

\(y_{t} \,=\, \phi^{2} y_{t-2} \,+ \phi \gamma x_{t-1} + \gamma x_{t} \,=\, \phi^{2} ( \phi y_{t-3} + \gamma x_{t-2} )\,+ \phi \gamma x_{t-1} + \gamma x_{t} \,=\, \phi^{3} y_{t-3} + \phi^{2} \gamma x_{t-2} \,+ \phi \gamma x_{t-1} + \gamma x_{t}\)

\(\vdots\)

\(y_{t} \,=\, \phi^{N} y_{\scriptscriptstyle {t-N}} \,+ \gamma \sum\limits_{i=0}^{N-1} \phi^{i} x_{t-i}\)

t 까지의 기간이 N이라면, 즉 t = N이라면

\(y_{t} \,=\, \phi^{t} y_{0} \,+ \gamma \sum\limits_{i=0}^{t-1} \phi^{i} x_{t-i}\), \(t\, \geq \,1\)

이 해는 시작점인 0 기인 경우다.

시작점이 없이 과거로 무한대로 계속되는 경우, 즉 \(N \to \infty\)인 경우

\(y_{t} \,=\, \lim\limits_{\scriptscriptstyle {N \to \infty}} \phi^{N} y_{\scriptscriptstyle {t-N}} \,+ \lim\limits_{\scriptscriptstyle {N \to \infty}} \gamma \sum\limits_{i=0}^{N-1} \phi^{i} x_{t-i}\)

\(| \phi |\,<\,1\) 이고, \(y_{t}\)가 유계수열(bounded sequence)이면 \(\, \lim\limits_{\scriptscriptstyle {N \to \infty}} \phi^{N} y_{\scriptscriptstyle {t-N}} \,=\,0\),

이를 transversality 조건이라 한다.

∴ \(y_{t} \,=\, \gamma \sum\limits_{i=0}^{\infty } \phi^{i} x_{t-i}\)

\(\left\{ x_{t} \right\}\)가 유계수열이고 단조수열이면 해는 수렴한다. 유한의 극한값이 존재한다.

\(\left\{ x_{t} \right\}\)가 유계수열이 아니면 해는 무한대로 발산한다. 즉 \(| \phi |\,<\,1\) 조건에도 불구하고 해는 발산한다.

\(x_{t} \,=\, \alpha\) 상수일 경우, \(\gamma \,=\,1\)이라면

\(y_{t} \,=\, \phi^{t} y_{0} \,+ \alpha \sum\limits_{i=0}^{t-1} \phi^{i} \,=\, \phi^{t} y_{0} \,+ \alpha \left( \frac{1- \phi^{t}}{1- \phi } \right) \,\)

\(=\, \phi^{t} \left( y_{0} \,-\, \frac{\alpha }{1- \phi } \right) \,+ \frac{\alpha }{1- \phi }\)

앞의 비동차 차분방정식의 해와 같은 결과이다.

d) 동차부분의 계수가 t의 함수인 경우

\(\phi_{t} \,=\,a+bt\) 의 형태일 경우

\(y_{t} \,=\,(a+bt)y_{t-1}\)

이 식의 해는

\(y_{1} \,=\,(a+b)y_{0}\)

\(y_{2} \,=\,(a+2b)y_{1} \,=\,(a+2b)(a+b)y_{0}\)

\(y_{3} \,=\,(a+3b)y_{2} \,=\,(a+3b)(a+2b)(a+b)y_{0}\)

\(\vdots\)

\(y_{t} \,=\, \prod_{i=1}^{t} (a+bi)y_{0} \,\)

일반적인 경우

\(y_{t} \,=\, \phi_{t-1} y_{t-1} + \gamma x_{t}\)

이 식의 해는

\(y_{t} \,=\, \prod_{i=0}^{t-1} \phi_{i} y_{0} \,+ \gamma \sum\limits_{k=0}^{t-1} x_{k} \prod_{i=k}^{t-1} \frac{\phi_{i}}{\phi_{k}}\)

증명은 해를 차분방정식에 대입하면 성립
