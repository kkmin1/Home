근의 안정성과 고계방정식

경제수학 II · 미분방정식 · 2계·고계 미분방정식

근의 안정성(stability of solution)

y '' (t)+ay ' (t)+by(t)=c , (a, b, c는 상수) 인 경우를 고려

r_{1} ,\,r_{2}를 근이라 하자.

i) 두 근이 실근인 경우(a_{1}^{2} -4a_{2} >0)

앞에서 일반해는 y(t)= \frac{c}{b} +c_{1} e^{r_{1} t} +c_{2} e^{r_{2} t} 이었므로

if r_{1} <0\;and\;r_{2} <0 ⇒ \lim\limits_{t \to \infty } {y(t)=}\lim\limits_{t \to \infty } ( \frac{c}{b} +c_{1} e^{r_{1} t} +c_{2} e^{r_{2} t} )\,=\, \frac{c}{b}

따라서 특성방정식의 두 근이 0보다 작으면 미분방정식의 해는 수렴한다.(안정적)

이때 \frac{c}{b}는 시간의 변동에 따라 불변이므로 이를 균형(equlibrium), 또는 정상상태(steady state)라 한다.

r_{1} <0\,,\;r_{2} <0 이면 2차 방정식의 근과 계수와의 관계에 의해

r_{1} +r_{2} =\,-a_{1} \,<0\,,\;r_{1} r_{2} =a_{2} \,>0

즉 a_{1} \,>0\,,\;a_{2} \,>0 이면 미분방정식의 해는 수렴한다.

if r_{1} >0\;and\;r_{2} >0 ⇒ \lim\limits_{t \to \infty } {y(t)=}\lim\limits_{t \to \infty } ( \frac{c}{b} +c_{1} e^{r_{1} t} +c_{2} e^{r_{2} t} )\,=\, \infty

따라서 두 근이 모두 양수이면 미분방정식의 해는 발산한다.

if r_{1} >0\;and\;r_{2} <0 ⇒ \lim\limits_{t \to \infty } {y(t)=}\lim\limits_{t \to \infty } ( \frac{c}{b} +c_{1} e^{r_{1} t} +c_{2} e^{r_{2} t} )\,=\, \infty

따라서 미분방정식의 해는 발산한다. 단 처음에 c_{2}가 c_{1}보다 큰 경우 해가 수렴하다가 발산한다. 따라서 이런 해를 안장경로(saddle path)라 한다. 특성방정식의 한 근이 양수이고 다른 한 근이 음수라서 미분방정식의 해가 안장경로를 갖는 경우는 경제적 모형에서 자주 발생한다.

ⅱ) 두 근이 중근인 경우(a_{1}^{2} -4a_{2} =0)

if r<0\; ⇒ \lim\limits_{t \to \infty } {y(t)=}\lim\limits_{t \to \infty } ( \frac{c}{b} +c_{1} e^{rt} +c_{2} te^{rt} )\,=\, \frac{c}{b}.............[16]

따라서 중근이 음수일 경우 미분방정식의 해는 수렴한다.

if r>0\; ⇒ \lim\limits_{t \to \infty } {y(t)=}\lim\limits_{t \to \infty } ( \frac{c}{b} +c_{1} e^{rt} +c_{2} te^{rt} )\,=\, \infty

따라서 중근이 양수일 경우 미분방정식의 해는 발산한다.

ⅲ) 두 근이 허근인 경우(a_{1}^{2} -4a_{2} <0)

동차부분의 해는 다음과 같았다.[17]

y_{c} (t)=c_{1} e^{\alpha t} \,\cos \beta t+c_{2} e^{\alpha t} \,\sin \beta t, where \alpha \,=\,- \frac{a_{1}}{2} \,,\; \beta \,=\, \frac{\, \sqrt {4a_{2} -a_{1}^{2}}}{2}

특수해는 y_{p} \,=\, \frac{c}{b}이므로

일반해는 y(t)= \frac{c}{b} \,+\,c_{1} e^{\alpha t} \,\cos \beta t+c_{2} e^{\alpha t} \,\sin \beta t

if \alpha <0 ⇔ \lim\limits_{t \to \infty } {y(t)=} \lim\limits_{t \to \infty } ( \frac{c}{b} \,+\,c_{1} e^{\alpha t} \,\cos \beta t+c_{2} e^{\alpha t} \,\sin \beta t)\,=\, \frac{c}{b}

즉 복소수의 실수부분이 0보다 작으면 미분방정식의 해는 발산한다.

\alpha =\,- \frac{a_{1}}{2} <0 ⇒ a_{1} >0

따라서 a_{1} >0이면 해는 수렴.

즉, 허근일 경우 2차 미분방정식에서 1차 도함수의 계수가 0보다 크면 안정적이다.

예) y '' (t)+3y ' (t)+2y(t)=4, y(0)=0,\;y'(0)=1

(풀이)

y를 상수로 보면 균형값은

2y*=4 ⇒ \,y*=2

특성방정식은

r^{2} +3r+2=0

(r+1)(r+2)=0

∴ r= -1 or –2 < 0

실수이면서 두 근 모두 0보다 작으므로 해는 수렴하고 안정적

일반해는

y(t)=2+\,A_{1} e^{-t} +A_{2} e^{-2t}

초기조건 y(0)=0,\;y'(0)=1 를 대입하면

{\begin{pmatrix}1 & 1 \\ -1 & \;-2\end{pmatrix}} {\begin{pmatrix}A_{1} \\ A_{2}\end{pmatrix}} = {\begin{pmatrix}-2 \\ 1\end{pmatrix}}

∴ A_{1} \,=\,-3,\;A_{2} \,=\,1

따라서 y(t)=2-3e^{-t} +e^{-2t}

(풀이끝)

고계선형미분방정식

상수 계수를 갖는 고차 HLDE

a_{n} y^{(n)} (t)+a_{n-1} y^{(n-1)} (t)+...+a_{1} y ' (t)+a_{0} y(t)=0 ..............①

①에 y(t)\,=\,e^{\lambda t} 를 대입하면

(a_{n} \lambda^{n} +a_{n-1} \lambda^{n-1} +...+a_{1} \lambda +a_{0} )e^{\lambda n} =0

위식이 항상 성립하기 위해서는 a_{n} \lambda^{n} +a_{n-1} \lambda^{n-1} +...+a_{1} \lambda +a_{0} =0 인 \lambda를 구함

미분방정식의 해는

y(t)\,=\, \sum\limits_{i=0}^{n} c_{i} e^{\lambda_{i} t}

모든 \lambda_{i}가 0보다 작으면 시간이 지남에 따라 해는 수렴. 그 중 하나라도 0보다 크면 해는 무한대로 발산
