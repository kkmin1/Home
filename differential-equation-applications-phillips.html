동태적 필립스곡선(Dynamic Philips curve)[112]

가정

(i) 기대를 반영한 필립스곡선

인플레이션율은 실업률과 역관계이다.[113]

명목임금은 기대인플레이션율과 정관계이다. 따라서 인플레이션율은 기대인플레이션율과 정관계이다.

\pi \,=a-bU-E+ \lambda \pi^{e} \,,\;a,\,b>0,\,0< \lambda \leq 1.............①

\pi = \frac{dP}{dt} /P : 인플레이션율, \pi^{e} : 기대인플레이션율, \lambda : 조정계수[114]

(ii) 적응적 기대가설

실질인플레이션율과 기대인플레이션율을 비교하여 기대인플레이션율을 수정한다.

\frac{d \pi^{e}}{dt} = \alpha ( \pi - \pi^{e} ),\;0< \alpha \leq 1 .............②

(iii) 통화정책

실업률 변화는 실질화폐잔고 증가율과 역관계이다.[115]

\frac{dU}{dt} \,=\,-k(m- \pi )\,,\,k>0 ..............③

m= \frac{dM}{dt} /M ; 명목화폐잔고 증가율

풀이

인플레이션율, 실업률, 기대인플레이션율 변수 세 개에 방정식 3개이므로 방정식을 풀 수 있다.

①을 ②에 대입하면

\frac{d \pi^{e}}{dt} = \alpha (a-bU-E+( \lambda -1) \pi^{e} )

이를 미분하면

\frac{d^{2} \pi^{e}}{dt^{2}} = \alpha ((-b) \frac{dU}{dt} +( \lambda -1) \frac{d \pi^{e}}{dt} )

=- \alpha b \frac{dU}{dt} + \alpha ( \lambda -1) \frac{d \pi^{e}}{dt}

③을 대입하면

\frac{d^{2} \pi^{e}}{dt^{2}} = \alpha bk(m- \pi^{e} )\,+ \alpha ( \lambda -1) \frac{d \pi^{e}}{dt} ...............④

②를 π에 대해 정리하면

\frac{d \pi^{e}}{dt} = \alpha ( \pi - \pi^{e} )

⇒ \pi = \frac{1}{\alpha } \frac{d \pi^{e}}{dt} + \pi^{e}

이를 ④에 대입하면

\frac{d^{2} \pi^{e}}{dt^{2}} = \alpha bk(m- \frac{1}{\alpha } \frac{d \pi^{e}}{dt} - \pi )\,+ \alpha ( \lambda -1) \frac{d \pi^{e}}{dt}

이를 정리하면

\frac{d^{2} \pi^{e}}{dt^{2}} +(bk+ \alpha ( \lambda -1)) \frac{d \pi^{e}}{dt} + \alpha bk \pi^{e} = \alpha bkm\,

이는 2계 미분방정식이다.

균형상태에서 \frac{d^{2} \pi^{e}}{dt^{2}} \,=\, \frac{d \pi^{e}}{dt} \,=\,0 이므로 정상상태값(steady-state value)은

\alpha bk \pi^{e} *= \alpha bkm\,

∴ \pi^{e} *\,=\,m

즉 균형에서 기대인플레이션율은 명목화폐증가율과 같다.

미분방정식의 특성방정식은

r^{2} +a_{1} r+a_{2} =0

∴ r_{1} ,\,r_{2} \,=\, \frac{-a_{1} \pm \sqrt {a_{1}^{2} -4a_{2}}}{2}

여기서 a_{1} \,=\,-(r_{1} +r_{2} )\,=\,bk+ \alpha ( \lambda -1)>0 , a_{2} \,=\,r_{1} r_{2} =\, \alpha bk>0

따라서 t기의 기대인플레이션율은

\pi^{e} (t)=m+A_{1} e^{r_{1} t} +A_{2} e^{r_{2} t} ..............⑤[116]

ⅰ) 두 근이 실근일 때(a_{1}^{2} -4a_{2} \geq 0)

a_{1} \,>0\,,\;a_{2} \,>0 이므로 r_{1} <0\,,\;r_{2} <0

따라서 t가 증가함에 따라 \pi^{e} 는 m으로 수렴한다.

ⅱ) 두 근이 허근일 때(a_{1}^{2} -4a_{2} <0)

a_{1} >0 이므로, 복소수의 실수부분 - \frac{a_{1}}{2} <0

\, THEREFORE \; \lim\limits_{t \to \infty } e^{r_{1} t} =\, \lim\limits_{t \to \infty } e^{r_{2} t} =0

따라서 t가 증가함에 따라 πe 는 진동하면서 m으로 수렴한다.

즉 실근, 허근 어느 경우든 기대인플레이션율은 명목화폐증가율로 수렴한다.

이제 인플레이션율 π를 구하자. ⑤을 t에 대해 미분하면

\frac{d}{dt} \pi^{e} (t)=r_{1} A_{1} e^{r_{1} t} +r_{2} A_{2} e^{r_{2} t}

이를 ②에 대입하면 인플레이션율 π는

\pi (t)= \frac{1}{\alpha } (r_{1} A_{1} e^{r_{1} t} +r_{2} A_{2} e^{r_{2} t} )+m+A_{1} e^{r_{1} t} +A_{2} e^{r_{2} t} \\ \\ =m+( \frac{r_{1}}{\alpha } +1)A_{1} e^{r_{1} t} +( \frac{r_{2}}{\alpha } +1)A_{2} e^{r_{2} t}

t가 증가함에 따라 π 는 두근이 실수이든 허근이든 m으로 수렴한다.[117]

즉 \lim\limits_{t \to \infty } {\pi (t)=m}

따라서 실질 인플레이션율은 명목화폐증가율로 수렴한다.

이제 실업률 U를 구하자.

식 ①를 U에 대해 정리하면

\pi \,=a-bU-E+ \lambda \pi^{e} \, 에서

U= \frac{a-E}{b} + \frac{1}{b} ( \lambda \pi^{e} - \pi )

U= \frac{a-E}{b} \,+ \frac{1}{b} \,[ \lambda (m+A_{1} e^{r_{1} t} +A_{2} e^{r_{2} t} )-m-( \frac{r_{1}}{\alpha } +1)A_{1} e^{r_{1} t} -( \frac{r_{2}}{\alpha } +1)A_{2} e^{r_{2} t} ] \\ \\ = \frac{a-E}{b} \,+ \frac{1}{b} [( \lambda -1)m+( \lambda - \frac{r_{1}}{\alpha } -1)A_{1} e^{r_{1} t} +( \lambda - \frac{r_{2}}{\alpha } -)A_{2} e^{r_{2} t} ]

\lim\limits_{t \to \infty } {U(t)\,= \frac{a-E}{b} \,+ \frac{(\lambda -1)m}{b}}

따라서 실업률은 \frac{a-E}{b} \,+ \frac{(\lambda -1)m}{b}} 로 수렴한다.[118]

자연실업률가설(natural rate of unemployment hypothesis)[119]

λ=1 이라 하면, 즉 기대인플레이션이 전기의 인플레이션을 100% 반영한다면 실업률 U는

U= \frac{a-E}{b}

즉 장기균형실업률은 명목화폐증가율에 관계없이 일정하다. 명목화폐증가율이 변하면 장기적으로 인플레이션율과 기대인플레이션율은 변하지만 장기적으로 실업률은 변하지 않는다. 따라서 장기적으로 실업률과 물가상승률은 상관관계가 없고 실업률은 수직인 곡선으로 표시되는데 이를 장기필립스곡선이라 한다. 통화론자인 프리드만은 장기필립스곡선이 수직선의 모양을 가지기 때문에 경제안정정책이 장기에서는 실업률을 낮추는데 아무 도움도 주지 못한다고 주장한다. 이를 자연실업률가설이라 한다.[120]
