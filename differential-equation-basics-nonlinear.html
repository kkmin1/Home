1차 비선형 미분방정식

변수분리

미분방정식이 다음의 형태일 경우 변수분리를 통해 해의 도출이 가능하다.

f(y)dy+g(t)dt\,=\;0

⇒ f(y)dy=\,-g(t)dt\,

양변 적분하면

\int f(y)dy=\,- \int g(t)dt\,

y에 대해 정리하면 미분방정식을 풀 수 있다.

예)

a) \frac{dy}{dt} +y^{2} =2, b) \frac{dy}{dx} \,=\, \frac{y^{2} +x^{2}}{xy}

(풀이)

a)

i) y=\pm \sqrt {2} 인 경우

양변 모두 만족하므로 답

ii) y != \pm \sqrt {2} 인 경우

\frac{dy}{2-y^{2}} =dt ...............①

\frac{1}{2-y^{2}} \,=\, \frac{a}{\sqrt {2} +y} + \frac{b}{\sqrt {2} -y} 에서

a=b= \frac{1}{2 \sqrt {2}}

따라서 ①은

\frac{1}{2 \sqrt {2}} (\, \frac{1}{\sqrt {2} +y} + \frac{1}{\sqrt {2} -y} )dy\,=\,dt

양변을 적분하면

\frac{1}{2 \sqrt {2}} (\,\ln ( \sqrt {2} +y)-\ln ( \sqrt {2} -y))\,=\,t+C_{1}

\,\ln ( \sqrt {2} +y)-\ln ( \sqrt {2} -y)\,=\,2 \sqrt {2} t+C_{2} , where C_{2} =2 \sqrt {2} C_{1}

⇒ \,\ln \frac{\sqrt {2} +y}{\sqrt {2} -y} \,=\,2 \sqrt {2} t\,+\,C_{2}

\, \frac{\sqrt {2} +y}{\sqrt {2} -y} \,=\,C_{3} e^{2 \sqrt {2} t} , where C_{3} =e^{c_{2}}

∴ y(t)= \frac{\sqrt {2} (C_{3} e^{2 \sqrt {2} t} -1)}{1+C_{3} e^{2 \sqrt {2} t}}

b)

\frac{dy}{dx} \,=\, \frac{y^{2} +x^{2}}{xy} \,=\, \frac{y}{x} \,+\, \frac{x}{y}

u=\, \frac{y}{x} 라 하면 y\,=\,ux

x에 대해 미분하면

y ' \,=\,u ' x\,+\,u

이를 원 문제에 대입하면

\,u ' x\,+\,u\,=\,u\,+\, \frac{1}{u}

⇒ \,u ' x\,=\, \frac{1}{u}

⇒ udu\,=\, \frac{1}{x} dx

양변 적분하면

\frac{1}{2} u^{2} \,+\,C_{1} \,=\,\ln|x|+C_{2}

⇒ u^{2} \,=\,2\ln|x|+C_{3}, where C_{3} \,=\,2(C_{2} \,-\,C_{1} )

⇒ u^{2} \,=\,\ln x^{2} +C_{3}

⇒ ( \frac{y}{x} ) ^{2} \,=\,\ln x^{2} +C_{3}

⇒ y\,=\,\pm x \sqrt {\,\ln x^{2} +C_{3}}

(풀이끝)

베르누이 방정식(Bernoulli equation)

다음과 같은 형태의 미분방정식을 베르누이 방정식이라 한다.

\frac{dy}{dt} +R(t)y=T(t)y^{m}, 단 m != 0,\,1 ................①

①을 y^{m}으로 나누면

y^{-m} \frac{dy}{dt} +R(t)y^{1-m} =T(t) .............②

z=y^{1-m} 라 하고 이를 t로 미분하면

\frac{dz}{dt} = \frac{dz}{dy} \frac{dy}{dt}=(1-m)y^{-m} \frac{dy}{dt}

⇒ \frac{dy}{dt} = \frac{y^{m}}{(1-m)} \frac{dz}{dt} ............③

③을 ②에 대입하면

\frac{1}{(1-m)} \frac{dz}{dt} +R(t)z\,=T\,(t)

⇒ \frac{dz}{dt} +(1-m)R(t)z\,=(1-m)T\,(t)

이는 \frac{dy}{dt} +u(t)y=v(t)의 형태임.

이에 대한 공식은

y(t)=e^{- \int {udt}} (C+ \int {ve^{ \int {udt}}} dt)

따라서

\frac{dz}{dt} +(1-m)R(t)z\,=(1-m)T\,(t)

⇒ z(t)=e^{- \int {(1-m)Rdt}} (C+ \int {(1-m)Te^{ \int {(1-m)Rdt}}} dt)

z(t)=y^{1-m} (t)이므로

∴ y(t)= \left\{ e^{- \int {(1-m)Rdt}} (C+ \int {(1-m)Te^{ \int {(1-m)Rdt}}} dt) \right\}^{m-1}

예) \frac{dy(t)}{dt} =y(t)+y^{3} (t)

(풀이)

양변을 y^{3} 으로 나누면

y^{-3} \frac{dy}{dt} =y^{-2} +1 ...............①

z= \frac{1}{y^{2}} 이라 하고 이를 미분하면

\frac{dz}{dt} =\,-2y^{-3} \frac{dy}{dt}

⇒ \frac{dy}{dt} =\,- \frac{1}{2} y^{3} \frac{dz}{dt} ...............②

②를 ①에 대입하면

- \frac{1}{2} \frac{dz}{dt} \,=\,z+1

⇒ \frac{dz}{dt} =\,-2-2z

⇒ \frac{1}{1+z} \frac{dz}{dt} =\,-2

양변 적분하면

\ln (1+z)\,=\,-2x+A_{0}

∴ z(t)\,=\,A_{1} e^{-2x} \,-1 , where A_{1} \,=\,e^{A_{0}}

y^{2} \,=\, \frac{1}{z} 이므로

y^{2} (x)= \frac{1}{A_{1} e^{-2x} -1}

∴ y(x)= {(A_{1} e^{-2x} -1) ^{- \frac{1}{2}}}

(풀이끝)

예) \frac{dk(t)}{dt} +nk(t)=s[k(t)] ^{\alpha } , n, s, α는 상수

(풀이)

양변을 k^{\alpha }로 나누면

k^{- \alpha } \frac{dk}{dt} +nk^{1- \alpha } =s ..............①

z\,=k^{1- \alpha } 라 하면

\frac{dz}{dt} = \frac{dz}{dk} \frac{dk}{dt} =(1- \alpha )k^{- \alpha } \frac{dk}{dt}

∴ \frac{\mathbf{d}\mathbf{k}}{\mathbf{d}\mathbf{t}} = \frac{\mathbf{k}^{\alpha }}{(1- \alpha )} \frac{\mathbf{d}\mathbf{z}}{\mathbf{d}\mathbf{t}} .............②

②를 ①에 대입하면

\frac{1}{(1- \alpha )} \frac{dz}{dt} +nz\,=s\,

⇒ \frac{dz}{dt} +(1- \alpha )nz\,=(1- \alpha )s\,

⇒ \frac{dz}{dt} \,=(1- \alpha )(s\,-nz)

⇒ \frac{1}{(s\,-nz)} \frac{dz}{dt} \,=\,1- \alpha

양변적분하면

\,- \frac{1}{n} \,\ln (s\,-nz)\,=\,(1- \alpha )t+A_{0}

⇒ \,\ln (s\,-nz)\,=\,-n(1- \alpha )t+A_{1} , where A_{1} \,=\,-nA_{0}

⇒ \,(s\,-nz)\,=\,A_{2} e^{-n(1- \alpha )t} , where A_{2} \,=\,e^{A_{1}}

∴ \,z(t)\,=\, \frac{s}{n} +A_{3} e^{-n(1- \alpha )t} , where A_{3} \,=\,- \frac{1}{n} A_{2}

z\,=k^{1- \alpha } 이므로

\,k^{1- \alpha } \,=\, \frac{s}{n} +A_{3} e^{n(1- \alpha )t}

⇒ \,k(t)\,=\, \left[ \frac{s}{n} +A_{3} e^{n(1- \alpha )t} \right] ^{\frac{1}{1- \alpha }}

(풀이끝)

Riccati equation

\frac{dy(t)}{dt} \,=A(t)y^{2} +B(t)y+C(t) ............①

이와 같은 미분방정식의 형태를 Riccati 방정식이라 한다.

C(t) = 0 이면 베르누이 미분방정식이 됨으로 이를 풀 수 있다.

Riccati 방정식을 풀기 위해 이를 베르누이 방정식 형태로 변환하는 것이 필요하다.

y_{p}를 Riccati 미분방정식을 만족하는 하나의 특수해라고 하면

\frac{dy_{p}}{dt} \,=A(t)(y_{p} ) ^{2} +B(t)y_{p} +C(t)

v=y-y_{p} 라 하면

y=v+y_{p} ..............②

\frac{dy}{dt} \,=\, \frac{dv}{dt} \,+\, \frac{dy_{p}}{dt} ............③

②, ③을 ①에 대입하면

\frac{dv}{dt} \,+\, \frac{dy_{p}}{dt} \,=A(t)(v+y_{p} ) ^{2} +B(t)(v+y_{p} )+C(t)

\,=A(t)(y_{p} ) ^{2} +B(t)y_{p} +C(t)+A(t)v^{2} +2A(t)vy_{p} +B(t)v

\,= \frac{dy_{p}}{dt} +A(t)v^{2} +2A(t)vy_{p} +B(t)v

∴ \, \frac{dv}{dt} \,=\,A(t)v^{2} +2A(t)vy_{p} +B(t)v

\,=\,A(t)v^{2} +[2A(t)y_{p} +B(t)]v

이는 v에 대하여 베르누이 방정식이다. 이제 이 방정식을 풀면 Riccati 방정식을 푸는 것이 된다.

Riccati 방정식은 다음의 공식으로 유도할 수도 있다.

z\,=\, \frac{1}{y-y_{p}} 라 하면 y\,=\, \frac{1}{z} \,+\,y_{p}

\frac{dy}{dt} \,=\, \frac{dy_{p}}{dt} - \frac{1}{z^{2}} \frac{dz}{dt}

이를 ①에 대입하면

A(t) \left[ \frac{1}{z} +y_{p} \right] ^{2} +B(t) \left[ \frac{1}{z} +y_{p} \right] +C(t) =\, \frac{dy_{p}}{dt} - \frac{1}{z^{2}} \frac{dz}{dt}

⇒ A(t)y_{p}^{2} +B(t)y_{p} +C(t)\,+\,A(t) \frac{1}{z^{2}} \,+\,[2A(t)y_{p} +B(t)] \frac{1}{z}=\, \frac{dy_{p}}{dt} - \frac{1}{z^{2}} \frac{dz}{dt}

⇒ A(t) \frac{1}{z^{2}} \,+\,[2A(t)y_{p} +B(t)] \frac{1}{z}=\,- \frac{1}{z^{2}} \frac{dz}{dt}

⇒ \frac{dz}{dt} \,=\,-A(t)\,-\,[2A(t)y_{p} +B(t)]z

예) \frac{dy}{dx} \,=\,(y-x) ^{2} +1 , y(0)= \frac{1}{2}

(풀이)

y_{p} =x라 하면

y_{p} '=1 이므로 위 방정식을 만족. 따라서 y_{p} =x는 하나의 특수해이다.

v=y-x 라 하면

y=v+x ⇒ y'=v'+1

이를 문제의 식에 대입하면

v ' +1=v^{2} +1

⇒ \frac{dv}{dx} \,=\,v^{2}

이는 변수분리법으로 풀 수 있다. 위 식을 다시 쓰면

\frac{dv}{v^{2}} =dx

양변 적분하면

⇒ - \frac{1}{v} \,+\,C_{1} \,=\,x+C_{2}

∴ v=\,- \frac{1}{x+C_{3}} \;, where C_{3} \,=\,C_{2} \,-\,C_{1}

y(0)= \frac{1}{2} 이므로 특수해 y_{p} =x는 일반해가 될 수 없다.

v=y-x 를 대입하면

y(x)=- \frac{1}{x+C_{3}} +x

y(0)=\,- \frac{1}{C_{3}} \,=\, \frac{1}{2} \,

THEREFORE \,C_{3} \,=\,-2

∴ y(x)= \frac{1}{2-x} +x

(풀이끝)

2차 비선형 미분방정식

Clairaut's equation

다음과 같은 형태의 미분방정식을 Clairaut 방정식이라 한다.

y(t)\,=\,t \frac{dy}{dt} \,+\,f( \frac{dy}{dt} )

위 식을 t에 대해 미분하면

y'\,=\,y'\,+\,ty''\,+\,f'(y')y''

⇒ [\,t\,+\,f ' (y ' )]y '' \,=\,0

따라서 y''\,=\,0 or \,t\,+\,f ' (y ' )\,=\,0

i) y''\,=\,0 인 경우

y'\,=\,C_{1} ⇒ y\,=\,C_{1} t\,+\,C_{2}

ii) \,t\,+\,f ' (y ' )\,=\,0 인 경우

일반해들의 그래프에 대한 포락선(envelope)을 이루는 하나의 해 y(x)를 정의하며, 이를 특이해(singular solution)라고 한다. 특이해는 보통 매개변수 표기 (x(p), y(p))로 나타내며, 여기서 p는 dy/dx를 의미한다.

상수 계수, y가 없는 경우

(y') ^{2} \,+\,ay'\,+b\,=\,0, a, b는 상수

y'\,=\,z 라 하면

z^{2} \,+\,az\,+b\,=\,0

∴ z\,=\, \frac{-a\pm \sqrt {a^{2} -4b}}{2}

∴ y\,=\, \frac{-a\pm \sqrt {a^{2} -4b}}{2} t\,+C_{1\,}

예)

a) (dy/dx)² - 3(dy/dx) = -2

b) y(dy/dx)² + 2x(dy/dx) - y = 0, y(0) = √5

c) x(dy/dx)² - 2y(dy/dx) + x = 0

d) (dy/dx)² + ay = bx² + cx, a, b, c는 상수

e) y\,=\,ty'\,+\,(y') ^{2}

(풀이)

a)

Put z = dy/dx

z² - 3z + 2 = 0

=> z = dy/dx = 1 or 2

=> y = x + c1 or 2x + c2

b)

let dy/dx = v

yv^2 + 2xv - y = 0

∴ v = (-x ± √(x²+y²)) / y

Let u = x²+y²

양변을 x에 대해 미분하면

du/dx = 2x + 2y dy/dx

du/dx = 2x + 2y * (-x ± √(x²+y²)) / y

du/dx = ± 2√(x²+y²)

du/dx = ± 2√u

du/2√u = ±dx

양변을 적분하면:

√u = ± x + C

√(x²+y²) = C ± x

x² + y² = C² ± 2Cx + x²

y² = C² ± 2Cx

When x = 0, y = √5

C = ±√5

y² = 5 ± 2√5 x

c)

let dy/dx = v

xv² - 2yv + x = 0

⇒ 2y = xv + x/v

x에 대해 미분하면

2v = 2y’ = v + xv’ + 1/v – xv’/v²

⇒ -v³ + xv²v’ + v – xv’ = 0

⇒ (v²-1)xv’ - v(v²-1) = 0

⇒ (v²-1)(xv’-v) = 0

i) v²=1

dy/dx = ±1

y = ±x+C

원 문제에 대입하면 C = 0

∴ y = ±x

ii) xv’ = v

v’/v = 1/x

lnv = lnx + C

v = Cx

dy/dx = Cx

y = Cx²/2 + D

원 문제에 대입하면

xC² - 2(Cx²/2 + D)Cx + x = 0

⇒ 2DC = 1

⇒ D = 1/2C

∴ y = Cx²/2 + 1/2C

d)

let y = Ax² + Bx + C

dy/dx = 2Ax + B

4A²x² + 4ABx + B² + aAx² + aBx + aC = bx² + cx

⇒ (4A²+aA-b)x² + (4AB+aB-c)x + B² + aC = 0

항상 성립하기 위해서는

4A²+aA-b = 0 ⇒ A* = [-a±√(²a+16b)]/8

4AB+aB-c = 0 ⇒ B* = c/(4A*+a)

B² + aC = 0 ⇒ C* = B*/a

y = A²*x+B*x+C

e)

u\,=\,y' 라 하면

y\,=\,tu\,+\,u^{2}

양변을 t에 관해 미분하면

y ' \,=\,u\,+\,tu ' \,+\,2uu '

\,tu ' \,+\,2uu ' \,=\,0, (∵ u\,=\,y')

⇒ (\,t\,+\,2u)u ' \,=\,0

∴ u ' \,=\,0 or \,t\,+\,2u\,=\,0

i) u ' \,=\,0

y\,=\,C_{1} t\,+\,C_{2}

이를 원 문제에 대입하면

\,C_{1} t\,+\,C_{2} \,=\,tC_{1} \,+\,C_{1}^{2}

∴ C_{2} \,=\,C_{1}^{2}

∴ y\,=\,C_{1} t\,+\,C_{1}^{2}

ii) \,t\,+\,2u\,=\,0

u\,=\,y'\,=\,- \frac{t}{2}

y\,=\,- \frac{t^{2}}{4} \,+\,C_{1}

이를 원 문제에 대입하면

\,- \frac{t^{2}}{4} \,+\,C_{1} \,=\,- \frac{t^{2}}{2} \,+\, \frac{t^{2}}{4}

∴ C_{1} \,=\,0

∴ y\,=\,- \frac{t^{2}}{4} \,

(풀이끝)
