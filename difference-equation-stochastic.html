4장. 확률차분방정식

확률차분방정식(stochastic difference equation)

차분방정식에 기댓값이 포함되어 있을 경우 확률차분방정식이라 한다. 확률차분방정식은 합리적 기대모형에서 많이 발생한다.

다음의 모형을 고려하자

\(y_{t} \,=\,ay_{t+1}^{e} \,+b\,x_{t}\), a, b는 상수

즉 현재의 상태(\(y_{t} \,\))는 다음기의 예측치(\(y_{t+1}^{e} \,\))와 다른 변수(\(\,x_{t}\))에 의존한다.

합리적 기대모형에서 미래의 예측치는 과거의 정보를 바탕으로 한 확률적 조건 기댓값이 되므로[35] 위 모형을 합리적 기대 가설하의 모형으로 바꾸면 다음과 같다.

\(y_{t} \,=\,aE_{t} (y_{t+1} | OMEGA )\,+\,bx_{t}\)

\(OMEGA\)는 지금까지의 정보를 의미, \(E_{t} (y_{t+1} | OMEGA )\)는 지금까지의 정보를 바탕으로 t기에 행하는 (t+1)기의 예측치로서 기대값

편의를 위해 \(OMEGA\)를 생략하자

\(y_{t} \,=\,aE_{t} (y_{t+1} )\,+\,bx_{t}\).............①

전방대입법

\(|a|\,<\,1\) 이면 전방대입법으로 해를 구한다.

한 기 늘리면

\(y_{t+1} \,=\,aE_{t+1} (y_{t+2} )\,+\,bx_{t+1}\)

양변에 기댓값을 취하면

\(E_{t} (y_{t+1} )\,=\,aE_{t} (E_{t+1} (y_{t+2} ))\,+\,bE_{t} (x_{t+1} )\)

\(=\,aE_{t} (y_{t+2} )\,+\,bE_{t} (x_{t+1} )\), (∵ \(E_{t} (y_{t+2} )\,=\,E_{t} (E_{t+1} (y_{t+2} ))\,\).......[36])

이를 ①에 대입하면

\(y_{t} \,=\,aE_{t} (y_{t+1} )\,+\,bx_{t}\)

\(=\,a[\,aE_{t} (y_{t+2} )\,+\,bE_{t} (x_{t+1} )]\,+\,bx_{t}\)

\(=\,a^{2} E_{t} (y_{t+2} )\,+\,abE_{t} (x_{t+1} )\,+b\,x_{t}\)

\(=\,a^{2} [aE_{t} (y_{t+3} )\,+\,bE_{t} (x_{t+2} )]\,+\,abE_{t} (x_{t+1} )\,+b\,x_{t}\), (∵ \(E_{t} (y_{t+2} )=\,aE_{t} (y_{t+3} )\,+\,bE_{t} (x_{t+2} )\))

\(=\,a^{3} E_{t} (y_{t+3} )\,+\,a^{2} bE_{t} (x_{t+2} )\,+\,abE_{t} (x_{t+1} )\,+b\,x_{t}\)

이런 식으로 N기까지 전개하면

\(y_{t} \,=\,a^{N} E_{t} (y_{\scriptscriptstyle {t+N}} )\,+\,a^{N-1} bE_{t} (x_{\scriptscriptstyle {t+N-1}} )\,+\, \cdots \,+\,a^{2} bE_{t} (x_{t+2} )\,+\,abE_{t} (x_{t+1} )\,+b\,x_{t}\)

\(=\,a^{N} E_{t} (y_{\scriptscriptstyle {t+N}} )\,+\,b \sum\limits_{i=0}^{N-1} a^{i} E_{t} (x_{t+i} )\)

\(N\, \to \infty\) 이면

\(y_{t} =\, \lim\limits_{\scriptscriptstyle {N \to \infty}} a^{N} E_{t} (y_{\scriptscriptstyle {t+N}} )\,+b\, \sum\limits_{i=0}^{\infty } a^{i} E_{t} (x_{t+i} )\)

transversility 조건에 따라 \(\, \lim\limits_{\scriptscriptstyle {N \to \infty}} a^{N} E_{t} (y_{\scriptscriptstyle {t+N}} )\,=\,0\) 이라면, 즉 \(y_{t}\)가 유계수열이라면

\(y_{t} \,=\,b\, \sum\limits_{i=0}^{\infty } a^{i} E_{t} (x_{t+i} )\)

\(|a|\,<\,1\) 이므로 \(x_{t}\)가 단조유계수열이면 해는 수렴한다.

lag 연산자를 이용하면 해를 쉽게 구할 수 있다.

\(y_{t} \,=\,aE_{t} (y_{t+1} )\,+\,bx_{t}\)

양변 기댓값을 취하면

⇒ \(E_{t} (y_{t} )\,=\,aE_{t} (y_{t+1} )\,+\,bE_{t} (x_{t} )\), (∵ \(E_{t} (y_{t} )\,=\,y_{t}\))

⇒ \(E_{t} (y_{t} )\,=\,aE_{t} (L^{-1} y_{t} )\,+\,bE_{t} (x_{t} )\)

⇒ \(E_{t} (y_{t} )\,=\,aL^{-1} E_{t} (y_{t} )\,+\,bE_{t} (x_{t} )\)

⇒ \((1-aL^{-1} )E_{t} (y_{t} )\,=\,bE_{t} (x_{t} )\)

⇒ \(E_{t} (y_{t} )\,=\, \frac{1}{1-aL^{-1}} bE_{t} (x_{t} )\)

\(\sum\limits_{i=0}^{\infty } (aL^{-1} ) ^{i} \,=\, \frac{1}{1-aL^{-1}}\) 이므로

\(E_{t} (y_{t} )\,=y_{t} \,=\;b \sum\limits_{i=0}^{\infty } (aL^{-1} ) ^{i} x_{t} \,=\,b \sum\limits_{i=0}^{\infty } a^{i} x_{t+i}\)

앞의 결과와 같은 결과이다.[37]

거품(bubble)

\(\, \lim\limits_{\scriptscriptstyle {N \to \infty}} a^{N} E_{t} (y_{\scriptscriptstyle {t+N}} )\,=\,0\) 조건을 완화하여 \(y_{t}\)가 유계수열이 아니라면, 거품항이 포함된다.

중첩의 원리에 따라 동차부분의 해가 여함수가 되므로 동차 확률차분방정식 \(y_{t} \,=\,aE_{t} (y_{t+1} )\,\)의 해를 구하면 된다. 이를 만족하는 해는 무수히 많다. 그 중에 대표적인 두 개를 소개한다.

i) 팽창형 거품(expanding bubble)

\(y_{t} \,=\,c \left( \frac{1}{a} \right) ^{t}\)는 위 동차 차분방정식의 해이다.

\(y_{t} \,=\,aE_{t} [c \left( \frac{1}{a} \right) ^{t+1} ]\,=\,c \left( \frac{1}{a} \right) ^{t} \,\)

따라서 위 동차 차분방정식을 만족한다.

\(y_{t} \,=\,aE_{t} (y_{t+1} )\,\) ⇒ \(E_{t} (y_{t+1} )\,=\, \frac{1}{a} y_{t}\), \(|a|\,<\,1\) 이므로 거품 해의 의미는 다음기의 기댓값은 항상 전기보다 크다는 의미이다.

경제적으로 해석하면 경제주체는 다음 기의 자산의 가치를 항상 전기의 값보다 높게 예상한다는 의미이다. 이와 같은 경제주체의 예상이 반복되면 경제는 자산가치가 무한정으로 폭등하는 버블현상이 일어날 것이다. 이런 기대를 자기실현적(self-fulling) 기대라 한다.

ii) 폭락형 거품(bursting bubble)

거품이 계속해서 팽창하기만 한다는 것은 비현실적이다. 어느 순간 폭락할 가능성이 존재한다. \(y_{t}\)가 \(\pi\)의 확률로 폭등하고 \((1- \pi )\)의 확률로 폭락한다면

\(y_{t+1} \,=\, {cases{\left( \frac{1}{a \pi } \right)&y_{t} \,+\, \epsilon_{t+1} \;with\,probability\, \pi \\ \; \epsilon_{t+1}&\;with\,probability\,1- \pi }}\)

\(\epsilon_{t}\)는 무작위 외부충격으로 기간간 상관관계는 없다. 즉 \(E_{t} ( \epsilon_{t+1} )\,=\,0\)

\(\epsilon_{t}\)는 평균이 0이고 경제 변수와 상관관계가 없는 외부의 무작위적 충격을 의미한다. 이런 오차를 경제적 용어로 흑점(sunspot)[38], 또는 백색소음(white noise)이라 한다. \(y_{t}\)가 \((1- \pi )\)의 확률로 \(\epsilon_{t}\)가 된다는 말은 \(y_{t}\)가 폭락하여 0이되고 외부적 확률변수만 남게 된다는 의미.

이는 동차차분방정식 \(y_{t} \,=\,aE_{t} (y_{t+1} )\,\)의 해가 된다.

\(y_{t} \,=\,aE_{t} [ \pi ( \left( \frac{1}{a \pi } \right) y_{t} \,+ \epsilon_{t+1} )\,+\,(1- \pi ) \epsilon_{t+1} ]\,\)

\(=\,aE_{t} [ \pi \left( \frac{1}{a \pi } \right) y_{t} \,+ \epsilon_{t+1} \,]\,\)

\(=\,aE_{t} [ \pi \left( \frac{1}{a \pi } \right) y_{t} \,]\,=\,y_{t}\)

후방대입법

\(|a|\,>\,1\) 이면 후방대입법으로 해를 구한다.

\(y_{t} \,=\,aE_{t} (y_{t+1} )\,+\,bx_{t}\)

\(y_{t+1} \,=\,E_{t} (y_{t+1} )\,+\, \epsilon_{t+1}\) 이므로, \(\epsilon_{t+1}\)은 예측오차

\(y_{t} \,=\,ay_{t+1} \,-a \epsilon_{t+1} \,+\,bx_{t}\)

⇒ \(y_{t+1} \,=\, \frac{1}{a} y_{t} \,- \frac{b}{a} x_{t} \,+\, \epsilon_{t+1} \,\)

이는 비동차 차분방정식이므로 transversality조건을 가정하면 이의 해는

\(\,y_{t} \,=\,- \frac{b}{a} \sum\limits_{i=0}^{\infty } \, \left( \frac{1}{a} \right) ^{i} x_{t-i} \,+\, \sum\limits_{i=0}^{\infty } \, \left( \frac{1}{a} \right) ^{i} \epsilon_{t-i}\)

\(|a|\,>\,1\) 이므로 \(x_{t}\), \(\epsilon_{t}\)가 단조유계수열이면 해는 수렴한다.

\(\epsilon_{t}\)는 흑점으로 평균이 0이고 다른 변수와 상관관계가 없는 외부의 무작위적 충격을 의미한다. 따라서 t기의 상태는 모형에서 제시하는 변수(\(x_{t}\))와 모형과 전혀 무관한 외생적 요인(\(\epsilon_{t}\))에 의해 결정된다.
