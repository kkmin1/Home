Cagan 초인플레이션 모형

경제수학 II · 차분방정식 · 5장. 경제학 응용 I

Cagan의 초인플레이션(hyperinflation) 모형

1) 적응적 기대하의 모형

가정

- 실질화폐수요는 기대 인플레이션률의 감소함수이다. 인플레이션률이 높을수록 화폐를 보유하려는 요구는 줄어든다. 단기적으로 화폐수요는 국민소득에 영향을 받지 않는다.

\(\frac{M_{t}^{d}}{P_{t}} \,=\, \left( \frac{P_{t+1}^{e}}{P_{t}} \right) ^{\alpha }\), \(\alpha \,<\,0\) .............①

\(M_{t}^{d}\) : t기의 화폐수요

\(P_{t}\) : t기의 물가수준

\(P_{t+1}^{e}\) : (t+1)기의 예상물가수준

기대방식은 적응적 기대를 가정. 다음 기의 인플레이션율은 전기의 인플레이션율에 의존

\(\frac{P_{t+1}^{e}}{P_{t}} \,=\, \left( \frac{P_{t} }{P_{t-1}} \right) ^{\lambda }\), \(\lambda \,>\,0\) ...............②

화폐의 수요와 공급은 균형, 화폐공급은 중앙은행에 의해서 외생적으로 결정된다.

\(M_{t}^{s} \,=\,M_{t}^{d} \,=\,M_{t}\) ..............③

풀이

①, ②, ③을 종합하면

\(\frac{M_{t} }{P_{t}} \,=\, \left( \frac{P_{t} }{P_{t-1}} \right) ^{\alpha \lambda }\)

양변 로그를 취하고, 소문자를 로그로 표현하면

\(m_{t} \,-\,p_{t} \,=\, \alpha \lambda (p_{t} \,-\,p_{t-1} )\)

⇒ \((1\,+\, \alpha \lambda )p_{t} \,=\, \alpha \lambda p_{t-1} \,+\,m_{t}\)

⇒ \(p_{t} \,=\, \left( \frac{\alpha \lambda }{1\,+\,\alpha \lambda } \right) p_{t-1} \,+\, \left( \frac{1}{1\,+\, \alpha \lambda } \right) m_{t}\)

이는 비동차항이 변수인 1차 차분방정식이다.

후방대입법으로 이 차분방정식의 해를 구하면 일반해는 거품항과 특수해로 구성된다.

\(p_{t} \,=\,c \left( \frac{\alpha \lambda }{1\,+\, \alpha \lambda } \right) ^{t} \,+\, \left( \frac{1}{1\,+\, \alpha \lambda } \right) \sum\limits_{i=0}^{\infty } \left( \frac{\alpha \lambda }{1\,+\, \alpha \lambda } \right) ^{i} m_{t-i}\), c는 임의의 상수

\(\left\{ m_{t} \right\}\)가 유계수열이고 \(\left | \frac{\alpha \lambda }{1\,+\, \alpha \lambda } \right | \,<\,1\) 이면 \(p_{t}\)는 장기적으로 수렴한다.

t기의 물가는 과거의 명목 통화공급량의 가중평균이며 최근의 통화공급량이 더 물가에 영향을 미친다.

거품항은 경제학적으로 예외적인 현상이므로 거품항을 제외한 모형을 고려하자.

i) 매기 통화공급이 일정한 경우(\(m_{t} \,=\,m\))

\(p_{t} \,=\, \left( \frac{1}{1\,+\, \alpha \lambda } \right) \sum\limits_{i=0}^{\infty } \left( \frac{\alpha \lambda }{1\,+\, \alpha \lambda } \right) ^{i} m\)

\(=\;m\).............[44]

물가는 통화공급만에 영향을 받고 매기 일정하다.

ii) 매기 통화공급이 일정 비율(g)로 증가하는 경우(\(m_{t} \,=\,gt\))[45]

\(p_{t} \,=\, \left( \frac{1}{1\,+\, \alpha \lambda } \right) \sum\limits_{i=0}^{\infty } \left( \frac{\alpha \lambda }{1\,+\, \alpha \lambda } \right) ^{i} m_{t-i}\)

\(=\, \left( \frac{1}{1\,+\, \alpha \lambda } \right) \sum\limits_{i=0}^{\infty } \left( \frac{\alpha \lambda }{1\,+\, \alpha \lambda } \right) ^{i} g(t-i)\)

\(=\,gt \left( \frac{1}{1\,+\, \alpha \lambda } \right) \sum\limits_{i=0}^{\infty } \left( \frac{\alpha \lambda }{1\,+\, \alpha \lambda } \right) ^{i} \,-\,g \left( \frac{1}{1\,+\, \alpha \lambda } \right) \sum\limits_{i=0}^{\infty } i \left( \frac{\alpha \lambda }{1\,+\, \alpha \lambda } \right) ^{i} \,\)

\(=\,gt\,-\,g(1\,+\, \alpha \lambda )\), (∵ \(\sum\limits_{i=0}^{\infty } i \left( \frac{\alpha \lambda }{1\,+\, \alpha \lambda } \right) ^{i} \,=\,(1+ \alpha \lambda ) ^{2}\).......[46])

따라서 물가는 통화공급 증가율과 같은 비율로 증가한다. 이는 물가가 통화공급에 의존한다는 화폐수량설을 뒷받침한다.[47] 따라서 인플레이션율을 낮추기 위해서 중앙은행은 통화공급을 줄여야 한다.

2) 완전 예측하의 모형

미래의 예측이 정확하다면

\(P_{t+1}^{e} \,=\,P_{t+1}\)

⇒ \(\frac{M_{t} }{P_{t}} \,=\, \left( \frac{P_{t+1} }{P_{t}} \right) ^{\alpha }\)

양변 로그를 취하고 소문자를 로그로 표현하면

\(m_{t} \,-\,p_{t} \,=\, \alpha (p_{t+1} \,-\,p_{t} )\), \(\alpha \,<\,0\)

⇒ \(p_{t+1} \,=\, \frac{\alpha \,-\,1}{\alpha } p_{t} \,+\, \frac{1}{\alpha } m_{t}\)

후방대입법으로 이 차분방정식의 해를 구하면

\(p_{t} \,=\,c \left( \frac{\alpha \,-\,1}{\, \alpha } \right) ^{t} \,+\, \left( \frac{1}{\, \alpha } \right) \sum\limits_{i=0}^{\infty } \left( \frac{\alpha \,-\,1}{\, \alpha } \right) ^{i} m_{t-i}\)

\(\frac{\alpha \,-\,1}{\, \alpha } \,>\,1\) 이므로 해는 발산한다.

따라서 전방대입법으로 해를 구하면

\(p_{t} \,=\,- \frac{1}{\alpha } \sum\limits_{i=1}^{\infty } \left( \frac{\alpha }{\alpha -1} \right) ^{i} m_{t+i} \,+\,c \left( \frac{\alpha -1}{\alpha } \right) ^{t}\), c는 임의의 상수

\(\frac{\alpha \,}{\, \alpha -1} \,<\,1\) 이므로 \(\left\{ m_{t} \right\}\)가 유계수열이라면 우변의 첫재항은 수렴한다. 그러나 거품항 때문에 시간의 경과에 따라 물가수준은 무한히 증가한다.

거품항은 경제학적으로 예외적인 경우를 의미하므로 c = 0 라면 \(\left\{ m_{t} \right\}\)가 유계수열이라 할 때 물가수준은 수렴한다. 이 경우 현재의 물가수준은 미래 통화공급의 가중평균을 의미한다.

i) 매기 통화공급이 일정한 경우(\(m_{t} \,=\,m\))

\(p_{t} \,=\,- \frac{1}{\alpha } \sum\limits_{i=1}^{\infty } \left( \frac{\alpha }{\alpha -1} \right) ^{i} m\)

\(=\,- \frac{1}{\alpha -1} \sum\limits_{i=0}^{\infty } \left( \frac{\alpha }{\alpha -1} \right) ^{i} m\,=\,m\)

물가는 통화공급만에 영향을 받고 매기 일정하다.

ii) 매기 통화공급이 일정 비율(g)로 증가하는 경우(\(m_{t} \,=\,gt\))

\(p_{t} \,=\,- \frac{1}{\alpha } \sum\limits_{i=1}^{\infty } \left( \frac{\alpha }{\alpha -1} \right) ^{i} m_{t+i}\)

\(=\,- \frac{1}{\alpha -1} \sum\limits_{i=0}^{\infty } \left( \frac{\alpha }{\alpha -1} \right) ^{i} g(t+i)\)

\(=\,-gt \frac{1}{\alpha -1} \sum\limits_{i=0}^{\infty } \left( \frac{\alpha }{\alpha -1} \right) ^{i} \,-\,g \frac{1}{\alpha -1} \sum\limits_{i=0}^{\infty } i \left( \frac{\alpha }{\alpha -1} \right) ^{i}\)

\(=\,gt\,-\,g( \alpha -1)\), (∵ \(\sum\limits_{i=0}^{\infty } i \left( \frac{\alpha }{\alpha -1} \right) ^{i} \,=\,( \alpha -1) ^{2}\)

따라서 물가는 통화공급 증가율과 같은 비율로 증가한다. 따라서 인플레이션율을 낮추기 위해서 중앙은행은 통화공급을 줄여야 한다. 적응적 기대가설과 같은 결론이다.

3) 합리적 기대하의 모형

합리적 기대하에서 예측치는 기댓값과 같으므로

\(P_{t+1}^{e} \,=\,E_{t} (P_{t+1} )\)

⇒ \(\frac{M_{t} }{P_{t}} \,=\, \left( \frac{E_{t} (P_{t+1} )}{P_{t}} \right) ^{\alpha }\)

양변 로그를 취하고 소문자를 로그로 표현하면

\(m_{t} \,-\,p_{t} \,=\, \alpha [E_{t} (p_{t+1} )\,-\,p_{t} ]\), \(\alpha \,<\,0\)

⇒ \(p_{t} \,=\, \frac{\alpha \,}{\alpha -1} E_{t} (p_{t+1} )\,-\, \frac{1}{\alpha -1} m_{t}\)

\(\frac{\alpha \,-\,1}{\, \alpha } \,>\,1\) 이므로 전방대입법으로 해를 구하면, \(p_{t}\)가 유계수열이라 할 경우

\(p_{t} \,=\, \frac{1}{\alpha -1} \sum\limits_{i=0}^{\infty } \left( \frac{\alpha }{\alpha -1} \right) ^{i} E_{t} (m_{t+i} \,)\)

따라서 물가는 미래 통화공급량 기댓값의 가중평균이다.

\(p_{t}\)가 유계수열이라는 가정을 제거하면 거품해가 포함될 수 있다.

팽창적 거품의 경우 해는

\(p_{t} \,= \frac{1}{\alpha -1} \, \sum\limits_{i=0}^{\infty } \left( \frac{\alpha }{\alpha -1} \right) ^{i+1} E_{t} (m_{t+i} )\,+\,c \left( \frac{\alpha -1}{\alpha } \right) ^{t}\), c는 임의 상수

투기적 초인플레이션(speculative hyperinflation)이 발생한다. 따라서 시간이 경과함에 따라 물가는 무한대로 폭등한다. 경제주체는 물가가 계속 오를 것을 예상하므로 이런 현상이 점점 증폭될 것이다. 이는 다음과 같이 설명할 수 있다. (아무런 경제적 근거 없이) 개별 경제주체들이 장차 인플레이션율이 상승하리라고 기대한다고 하면 그들은 물가가 더 오르기 전에 화폐를 처분하고 토지나 생필품과 같은 실물을 구입함으로써 자기들의 자산 가치를 보호하고자 할 것이다. 그러나 모든 경제주체들이 다함께 그와 같이 행동한다면 물가는 상승하고 그들의 기대는 결국 현실로 실현되고 만다. 그런데, 이때 놀라운 것은 통화 증가율은 일정하게 유지되고 있다는 사실이다. 즉, 통화량이 일정하게 유지된다 해도 모든 개별 경제주체들이 물가가 장차 상승하리라는 기대를 형성하게 되면 결국 그와 같은 기대는 실현되고 만다는 것이다. 따라서 이와 같은 물가상승에 대한 기대는 자기실현적(self-fullfilling)이라고 한다.

폭락형 거품의 경우 해는

\(p_{t} \,= \frac{1}{\alpha -1} \, \sum\limits_{i=0}^{\infty } \left( \frac{\alpha }{\alpha -1} \right) ^{i+1} E_{t} (m_{t+i} )\,+\,b^{t}\)

where \(b_{t} \,=\, {cases{\left( \frac{1+r}{ \pi } \right)&b_{t-1} \,+\, \epsilon_{t+1} \;with\,probability\, \pi \\ \; \epsilon_{t+1}&\;with\,probability\,1- \pi }}\)

물가는 기본적으로 통화공급의 기대치에 의존한다. 단 경제주체의 물가상승 기대에 편승하여 시간이 경과함에 따라 물가는 계속 증가할 가능성이 있지만, 어느 순간 폭락할 가능성도 존재한다.
