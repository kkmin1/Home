대각행렬화(diagonalization)

(1) 고유치가 서로 다를 경우

A를 대각행렬(D)로 만들 수 있다면 미분방정식의 해는 쉽게 도출된다.

D = {\begin{pmatrix}\lambda_{1} & 0 & \cdots & 0 \\ 0 & \lambda_{2} & \cdots & 0 \\ \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & \cdots & \lambda_{n}\end{pmatrix}}

z’ = Dz 라 하면

{\begin{pmatrix}z ' _{1} \\ z ' _{2} \\ \vdots \\ z ' _{n}\end{pmatrix}} = {\begin{pmatrix}\lambda_{1} & 0 & \cdots & 0 \\ 0 & \lambda_{2} & \cdots & 0 \\ \vdots & \vdots & \ddots & \vdots \\ 0 & 0 & \cdots & \lambda_{n}\end{pmatrix}}{\begin{pmatrix}z_{1} \\ z_{2} \\ \vdots \\ z_{n}\end{pmatrix}} = {\begin{pmatrix}\lambda_{1} z_{1} \\ \lambda_{2} z_{2} \\ \vdots \\ \lambda_{n} z_{n}\end{pmatrix}}

풀어쓰면

z' _{1} = \lambda_{1} z_{1}

z ' _{2} = \lambda_{2} z_{2}

\cdots\cdots

z ' _{n} = \lambda_{n} z_{n}

이들 미분방정식의 해는 쉽게 도출된다.

∴ {\begin{pmatrix}z_{1} \\ z_{2} \\ \vdots \\ z_{n}\end{pmatrix}} = {\begin{pmatrix}c_{1} e^{\lambda_{1} t} \\ c_{2} e^{\lambda_{2} t} \\ \vdots \\ c_{n} e^{\lambda_{n} t}\end{pmatrix}} , where c_{i} 는 상수

이제 A를 대각행렬(D)로 만든다.

A 의 대각행렬화는 대각행렬화정리에 의해[18]

A = PDP-1 , where D = {\begin{pmatrix}\lambda_{1} & 0 & ... & 0 \\ 0 & \lambda_{2} & ... & 0 \\ \vdots & \vdots & \ddots & \vdots \\ 0 & ... & 0 & \lambda_{n}\end{pmatrix}} , \lambda_{ i} : A 의 고유치(eigen value)

P = (p1, ..., pn) , pi 는 고유벡터(eigen vector)

P 는 고유 벡터들로 이루어진 행렬

이제 고유벡터행렬과 그의 역행렬을 각각 A에 후방곱, 전방곱하면 다음이 구해진다.

D = P-1AP

이제 y = Pz 는 원래의 선형 연립미분방정식 y’ = Ay 의 해가 된다.

(여기서 z는 z’ = Dz 의 해)

이를 증명하기 위해 y = Pz 를 y’ = Ay 에 대입하여 등식이 성립함을 보이면 된다.

y’ = \frac{d}{dt}y = \frac{d}{dt}Pz = P\frac{d}{dt}z = Pz’ = PDz , (∵ z’ = Dz)

= P(P-1AP)z , (∵ D = P-1AP)

= APz = Ay

따라서 y = Pz 은 y’ = Ay 의 해가 된다.

즉,

y = Pz = (p1, ..., pn){\begin{pmatrix}c_{1} e^{\lambda_{1} t} \\ c_{2} e^{\lambda_{2} t} \\ \vdots \\ c_{n} e^{\lambda_{n} t}\end{pmatrix}} = \sum\limits_{i=1}^{n} c_{i} e^{\lambda_{i} t}pi ⇐ 스칼라가 아닌 (n×1)벡터임에 주의

복잡하게 설명했지만 다음과 같이 설명할 수 있다. 단일변수인 경우

y'(t)=ay(t) 의 해는 y(t)\,=\,ce^{at} , where c는 상수

y’(t) = Ay(t) 의 해는 단일변수인 경우로부터 다음과 같이 짐작할 수 있다.

y(t) = pi\mathbf{e}^{\lambda_{\mathbf{i}} \mathbf{t}} ............① , where \lambda_{i}는 A의 한 고유치, pi는 A의 한 고유벡터

①를 y’(t) = Ay(t)에 대입하면

\lambda_{\mathbf{i}}pi\mathbf{e}^{\lambda_{\mathbf{i}} \mathbf{t}} = Api\mathbf{e}^{\lambda_{\mathbf{i}} \mathbf{t}} , (∵ y‘(t) = \lambda_{i}pi\mathbf{e}^{\lambda_{\mathbf{i}} \mathbf{t}})

⇒ \lambda_{i}pi = Api

⇒ (A-\lambda_{i}I)pi = 0 ............②

이 등식이 성립해야 해가 된다. 그런데 ②는 특성방정식을 나타내는 식이고 따라서 \lambda_{i}, pi는 A의 고유치와 고유벡터이다.

다시 말하면 A의 고유치와 고유벡터로 이루어진 y(t) = pi\mathbf{e}^{\lambda_{\mathbf{i}} \mathbf{t}} 가 y’(t) = Ay(t) 의 해임을 알 수 있다.

일반해는 서로 독립인 근들의 선형결합으로 표시된다.

y(t) = \sum\limits_{i=1}^{n} c_{i} e^{\lambda_{i} t}pi

= PcTe^{\mathbf{b}\mathbf{o}\mathbf{l}\mathbf{d}{\lambda } \mathbf{t}}

where P = (p1, ..., pn), cT = (c_{1} ,c_{2} ,\,...\,,c_{n}), e^{\mathbf{b}\mathbf{o}\mathbf{l}\mathbf{d}{\lambda } \mathbf{t}} = {\begin{pmatrix}e^{\lambda_{1} t} \\ e^{\lambda_{2} t} \\ \vdots \\ e^{\lambda_{n} t}\end{pmatrix}}

※ A가 대각행렬일 경우 고유벡터행렬은 항등행렬 I 로 표시하면 된다.

(2) 고유치가 중복일 경우(고유벡터가 n개가 아닐 경우)[19]

고유벡터가 서로 독립이 아니므로 역행렬이 존재하지 않는다.

단일변수의 경우 특성근이 중근일 경우에는 먼저 구한 해에 t를 곱하여 독립인 다른 해를 구했다. y_{1} (t) 가 먼저 구한 해라면 다른 해 y_{2} (t) 는

y_{2} (t) = ty_{1} (t)

이로 부터 연립미분방정식의 경우에도 해를 유추하면

y(t) = tp\mathbf{e}^{\lambda \mathbf{t}} 가 해가 되는지를 판정.

y’(t) = Ay(t)에 대입하면

p\mathbf{e}^{\lambda \mathbf{t}} + tλp\mathbf{e}^{\lambda \mathbf{t}} = Atp\mathbf{e}^{\lambda \mathbf{t}}

⇒ p + tλp = Atp

⇒ t(A - λI)p + p = 0

이 등식이 항상 성립하기 위해서는 (A - λI)p = 0 , p = 0

첫째 등식은 고유치와 고유벡터의 성질이므로 성립하나 두 번째 식은 고유벡터가 항상 0 벡터이어야 하므로 불가능.

따라서 y(t) = tp\mathbf{e}^{\lambda \mathbf{t}} 는 해가 되지 못한다.

이제 해가 y(t) = tp\mathbf{e}^{\lambda \mathbf{t}} + q\mathbf{e}^{\lambda \mathbf{t}} 형태라고 짐작하고 y’(t) = Ay(t)에 대입하면

p\mathbf{e}^{\lambda \mathbf{t}} + tλp\mathbf{e}^{\lambda \mathbf{t}} + λq\mathbf{e}^{\lambda \mathbf{t}} = Atp\mathbf{e}^{\lambda \mathbf{t}} + Aq\mathbf{e}^{\lambda \mathbf{t}}

⇒ t(A - λI)p + (A - λI)q = p

이 식이 항상 성립하기 위해서는

∴ (A - λI)p= 0 ............①

(A - λI)q = p ............②

①은 λ가 고유치, p가 고유벡터이면 성립.

②는 ②를 만족하는를 q구함

따라서 λ, p, q 가 ①, ②를 만족시키면 y(t) = tp\mathbf{e}^{\lambda \mathbf{t}} + q\mathbf{e}^{\lambda \mathbf{t}} 는 해가 됨

따라서 일반해는

y(t) = c_{1} e^{\lambda t}p + c_{2} (te^{\lambda t}p + e^{\lambda t}q)

(3) 고유치가 복소수일 경우

(정리)

고유벡터 하나가 p{}_{1} = a + ib 라면 다른 하나는 p{}_{2} = a - ib, 즉 고유벡터는 켤레복소수이다.

(증명)

복소수가 0라면 켤레복소수도 0이므로

(A-\lambda_{1}I)p{}_{1} = 0 ⇒ Conj[(A-\lambda_{1}I)p{}_{1}] = 0

Conj[(A-\lambda_{1}I)p{}_{1}] = (A-Conj(\lambda_{1})I)Conj(p{}_{1}) = (A-\lambda_{2}I)p{}_{2} = 0

따라서 \lambda_{2}에 대응하는 다른 고유벡터는 켤레복소수인 p{}_{2}가 된다.

Q.E.D.

\lambda_{1} \,,\, \lambda_{2} \,=\, \alpha \pm \beta i 인 경우

y(t) = c_{1} e^{\lambda_{1} t}p1+c_{2} e^{\lambda_{2} t}p2

= c_{1} e^{( \alpha +i \beta )t}(a + ib)+c_{2} e^{( \alpha -i \beta )t}(a - ib)

y(t)가 실수인데 해가 복소수의 형태를 띠고 있는 것 같아 모순인 것 같지만 해는 사실상 실수이다. 그 이유는 \lambda_{1} \,,\, \lambda_{2} \,가 켤레복소수인 경우 c_{1} ,\,c_{2}도 켤레복소수이기 때문이다.

y(t) = c_{1}w1(t) + c_{2}w2(t)

where

w1(t) = e^{( \alpha +i \beta )t}(a + ib) = e^{ \alpha t} (\cos \beta t\,+\,i\,\sin \beta t)(a + ib)

= e^{\alpha t}[(\cos \beta t\,a -\,\sin \beta tb) + i(\,\sin \beta ta + \cos \beta t\,b)]

w2(t) = e^{( \alpha -i \beta )t}(a - ib) = e^{\alpha t} (\cos \beta t\,-\,i\,\sin \beta t)(a - ib)

= e^{\alpha t}[(\cos \beta t\,a -\,\sin \beta tb) - i(\,\sin \beta ta + \cos \beta t\,b)]

w1(t) = x1(t) + ix2(t)

where

x1(t) = e^{\alpha t}(\cos \beta t\,a - \,\sin \beta tb)

x2(t) = e^{\alpha t}(\,\sin \beta ta + \cos \beta t\,b)

w1(t)은 ①의 해이므로

w1(t)’ = Aw1(t)

⇒ x1(t)’ + ix2(t)’ = A(x1(t) + ix2(t)) = Ax1(t) + iAx2(t)

두 복소수가 같으려면 실수부, 허수부가 각각 같아야 하므로

x1(t)’ = Ax1(t)

x2(t)’ = Ax2(t)

따라서 x1(t), x2(t)는 ①의 근이다.

y(t) = c_{1}w1(t) + c_{2}w2(t)

= c_{1}(x1(t) + ix2(t)) + c_{2}(x1(t) - ix2(t))

= (c_{1}+c_{2})x1(t) + i(c_{1}-c_{2})x2(t))

c_{1} ,\,c_{2}는 켤레복소수이므로 c_{1} =u+vi,\;c_{2} =u-vi 라고 하면

y(t) = 2ux1(t) - 2vx2(t)

a, b, u, v는 실수이므로 해는 실수임을 알 수 있다. 따라서 최종해는 다음과 같이 표현된다.

y(t) = k_{1}x1(t) + k_{2}x2(t), k_{1} ,\,k_{2}는 임의 상수

y(t) = k_{1}e^{\alpha t}(\cos \beta t\,a -\,\sin \beta tb) + k_{2}e^{\alpha t}(\,\sin \beta ta + \cos \beta t\,b), k_{1} ,\,k_{2}는 임의 상수

예)

선형 자율시스템의 안정성(stability of linear autonomous system)[20]

안정성은 시간이 지남에 따라 변수값이 어떻게 변하는 것을 보는 것이므로 t > 0 임을 가정한다.

다음의 선형 자율 연립미분방정식을 고려하자.

y’ = Ay ............①

Ay = 0 의 해 y*를 임계점(critical point), 또는 균형점(equilibrium point)이라고 한다.

이때 상수로 구성된 임계점은 ①의 해가 된다.

즉, y* = y0, (y0는 상수)는 위 연립미분방정식의 해이다.

∵ y’ = 0 = Ay*

Ay = 0에서 A가 비특이행렬이면 y = 0 가 유일한 임계점

미분방정식의 해가 t가 커짐에 따라 임계점에 접근한다면 안정적(stable)이라고 함

(2 × 2 행렬의 경우)

tr(A)\,=\, \lambda_{1} \,+\, \lambda_{2}, det(A)\,=\, \lambda_{1} \lambda_{2} 이므로

\phi ( \lambda )= \lambda^{2} -tr(A) \lambda +det(A)

(근의 판정)

tr(A) ^{2} \,-\,4det(A)\, \geq \,0 이면 실근

tr(A) ^{2} \,-\,4det(A)\,<\,0 이면 허근

(i) 실수인 두 개의 고유치(\lambda_{1} \,,\; \lambda_{2})를 갖는 경우(특성방정식의 근이 두 개의 실근)

y(t) = c_{1} e^{\lambda_{1} t}p1+c_{2} e^{\lambda_{2} t}p2 , where p1, p2 는 고유벡터

\lambda_{1} <0\;and\; \lambda_{2} <0 ⇒ \lim\limits_{t \to \infty }y(t) = \lim\limits_{t \to \infty }(c_{1} e^{\lambda_{1} t}p1+c_{2} e^{\lambda_{2} t}p2) = 0

두 개의 고유치 모두 0 보다 작으면(det(A)\,>\,0, tr(A)\,<\,0) 해는 안정적이고 t가 증가함에 따라 c_{1} +c_{2}에 수렴한다.

두 개의 고유치 모두 0 보다 크면(det(A)\,>\,0, tr(A)\,>\,0) 해는 불안정하고 무한대로 발산한다.

두 개의 고유치 중 적어도 하나가 0 보다 크면(det(A)\,<\,0) 해는 불안정하고 무한대로 발산한다. 특히 이런 경로를 안장경로(saddle path)라 한다.

(ii) 중복의 고유치가 있는 경우(A가 대각화 불가능행렬)

y(t) = c_{1} e^{\lambda t}p + c_{2} (te^{\lambda t}p + e^{\lambda t}q), where q는 (A-λI)q = p 의 해

\lambda <0\; 이면 해는 안정적

\lambda \geq 0\;이면 해는 발산

(iii) 두 개의 고유치(\lambda_{1} \,,\; \lambda_{2})가 복소수인 경우(특성방정식의 근이 두 개의 허근)

두 근이 허근일 때 해는 다음과 같이 변형되므로

y(t) = c_{1}e^{\alpha t}(\cos \beta t\,a -\,\sin \beta tb) + c_{2}e^{\alpha t}(\,\sin \beta ta + \cos \beta t\,b), c_{1} ,\,c_{2}는 임의 상수

a, b는 상수의 벡터이고 삼각함수 부분은 절대값이 2보다 작으므로

\alpha <0 이면 해는 t가 증가함에 따라 나선형으로 수렴한다.[21]

\alpha =0 이면 해는 t가 증가함에 따라 원형의 모양을 가지면서 회전한다.[22]

\alpha >0 이면 해는 t가 증가함에 따라 나선형으로 발산한다.

(결론)

(i), (ii), (iii)에 공통으로 해당되는 사항은 특성방정식의 근이 어떤 형태이던 실수 부분이 0보다 작다면 해는 안정적이다.

상변화도(phase portrait)[32]

Now let us consider the nonhomogeneous system

y’ = Ay + b

Where b is a constant vector. The system above is explicitly:

x1′ = a x1 + b x2 + g1

x2′ = c x1 + d x2 + g2

As before, we can find the critical point by setting x1′ = x2′ = 0 and solve the resulting nonhomgeneous system of algebraic equations. The origin will no longer be a critical point, since the zero vector is never a solution of a nonhomogeneous linear system. Instead, the unique critical point (as long as A has nonzero determinant, there remains exactly one critical point) will be located at the solution of the system of algebraic equations:

0 = a x1 + b x2 + g1

0 = c x1 + d x2 + g2

Once we have found the critical point, say it is the point (x1, x2) = (α, β), it then could be moved to (0, 0) via the translations χ1 = x1 − α and χ2 = x2 − β.

The result after the translation would be the homogeneous linear system

χ ′ = Aχ.

The two systems (before and after the translations) have the same coefficient matrix.* Their respective critical points will also have identical type and stability classification. Therefore, to determine the type and stability of the critical point of the given nonhomogeneous system, all we need to do is to disregard b, then take its coefficient matrix A and use its eigenvalues for the determination, in exactly the same way as we would do with the corresponding homogeneous system of equations.

Suppose (x1, x2) = (α, β) is the critical point of the system. That is

0 = a α + b β + g1

0 = c α + d β + g2

Now apply the translations χ1 = x1 − α and χ2 = x2 − β.

We see that

x1 = χ1 + α, x2 = χ2 + β, χ1′ = x1′, and χ2′ = x2′.

Substitute them into the system x′ = Ax + b:

x1′ = χ1′ = a x1 + b x2 + g1 = a(χ1 + α) + b(χ2 + β) + g1

= a χ1 + b χ2 + (a α + b β + g1) = a χ1 + b χ2

x2′ = χ2′ = c x1 + d x2 + g2 = c(χ1 + α) + d(χ2 + β) + g2

= c χ1 + d χ2 + (c α + d β + g2) = c χ1 + d χ2

That is, with the new variables χ1 and χ2 the given system has become

χ1′ = a χ1 + b χ2

χ2′ = c χ1 + d χ2

Notice it has the form χ ′ = Aχ. That is, it is a homogeneous system (with the critical point at the origin) whose coefficient matrix is exactly A, the same as the original system’s. Hence, b could be disregarded, and a determination of the type and stability of the critical point of the system (with or without the translations) could be based solely on the coefficient matrix A.

비선형 연립미분방정식(nonlinear differential equation systems)

y’ = F(y)

비선형 연립미분방정식의 경우 직접적으로 미분방정식의 해를 구할 수 없는 경우가 대부분이다. 따라서 상변화도를 그려 해의 모양을 추측한다. 또한 컴퓨터를 이용한 수치분석을 통해 해의 모양을 도출한다.

변수 2개, 함수 2개인 경우

y ' _{1} (t)\,=\,f_{1} (y_{1} ,\,y_{2} )

y ' _{2} (t)\,=\,f_{2} (y_{1} ,\,y_{2} )

Like a linear system, the critical points are found by setting y ' _{1} (t)\,=\,y' _{2} (t)\,=\,0, and solve the resulting system

\,f_{1} (y_{1} ,\,y_{2} )\,=\,0

\,f_{2} (y_{1} ,\,y_{2} )\,=\,0

Unlike a linear system, a nonlinear system could have none, one, two, three, or any number of critical points.

Since there might be multiple critical points present on the phase portrait, each trajectory could be influenced by more than one critical point.

the type and stability of each critical point need to be determined locally (in a small neighborhood on the phase plane around the critical point in question) on a case–by- case basis.

We will approximate the behavior of the nearby trajectories using the linearizations (i.e. the tangent approximations) of f_{1} and f_{2} about each critical point. This converts the nonlinear system into a linear system whose phase portrait approximates the local behavior of the original nonlinear system near the critical point.

start with the lineariztions of f_{1} and f_{2} such a linearization is just the 3 lowest order terms in the Taylor series expansion of each function) about the critical point \,(y_{1} ,\,y_{2} )\, = (α, β).

y ' _{1} (t)\,=\,f_{1} (y_{1} ,\,y_{2} ) \approx f_{1} ( \alpha ,\, \beta )+ \frac{\partial f_{1}}{\partial y_{1}} (y_{1} - \alpha )+ \frac{\partial f_{1}}{\partial y_{2}} (y_{2} - \beta )

y ' _{2} (t)\,=\,f_{2} (y_{1} ,\,y_{2} ) \approx f_{2} ( \alpha ,\, \beta )+ \frac{\partial f_{2}}{\partial y_{1}} (y_{1} - \alpha )+ \frac{\partial f_{2}}{\partial y_{2}} (y_{2} - \beta )

But since (α, β) is a critical point, so f_{1}(α, β) = 0 = f_{2}(α, β), the above

linearizations become

y ' _{1} (t)\, \approx \frac{\partial f_{1}}{\partial y_{1}} (y_{1} - \alpha )+ \frac{\partial f_{1}}{\partial y_{2}} (y_{2} - \beta )

y ' _{2} (t)\, \approx \frac{\partial f_{2}}{\partial y_{1}} (y_{1} - \alpha )+ \frac{\partial f_{2}}{\partial y_{2}} (y_{2} - \beta )

As before, the critical point could be translated to (0, 0) and still retains its

type and stability, using the substitutions χ = x − α and γ = y − β. After the

translation, the approximated system becomes

y ' _{1} (t)\,= \frac{\partial f_{1}}{\partial y_{1}} y_{1} + \frac{\partial f_{1}}{\partial y_{2}} y_{2}

y ' _{2} (t)\,= \frac{\partial f_{2}}{\partial y_{1}} y_{1} + \frac{\partial f_{2}}{\partial y_{2}} y_{2}

행렬형태로 고치면

{\begin{pmatrix}\frac{dy_{1}}{dt} \\ \frac{dy_{2}}{dt}\end{pmatrix}} = {\begin{pmatrix}\frac{\partial f_{1}}{\partial y_{1}}&\frac{\, \partial f_{1}}{\partial y_{2}} \\ \frac{\partial f_{2}}{\partial y_{1}}&\, \frac{\partial f_{2}}{\partial y_{2}}\end{pmatrix}}{\begin{pmatrix}y_{1} (t) \\ y_{2} (t)\end{pmatrix}}

It is now a homogeneous linear system with a coefficient matrix

J = {\begin{pmatrix}\frac{\partial f_{1}}{\partial y_{1}}&\frac{\, \partial f_{1}}{\partial y_{2}} \\ \frac{\partial f_{2}}{\partial y_{1}}&\, \frac{\partial f_{2}}{\partial y_{2}}\end{pmatrix}}

That is, it is a matrix calculate by plugging in x = α and y = β into the matrix

of first partial derivatives. This matrix of first partial derivatives, J, is often called the Jacobian matrix.

It just needs to be calculated once for each nonlinear system. For each critical point of the system, all we need to do is to compute the coefficient matrix of the linearized system about the given critical point (x, y) = (α, β), and then use its eigenvalues to determine the (approximated) type and stability.
